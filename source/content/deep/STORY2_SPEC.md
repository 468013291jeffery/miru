# MIRU 互动剧本写作规范 v2（《打烊之后》第 1 章）

MIRU 是一个聊天式互动恋爱剧 App。剧情一句一句出现在手机屏幕上，背景是当前场景的照片。读者扮演 **Nico**，轮到 Nico 说话时屏幕上出现 2–3 个粉色气泡选项。上一版剧本被用户骂了：**中文像翻译腔、像 AI 写的，看不懂、玩不明白**。这一版的头号目标：**像真人说话，让一个普通中国读者一看就懂、想往下看**。

## 一、语言（最重要）

**中文是原创，不是翻译。先写中文，再写英文。**

- 写成国产短剧 / 网文对话的感觉：口语、短句、有情绪、有梗。人物说话就像朋友在酒吧里聊天：“不是吧你？”“行行行，我闭嘴。”“你再说一遍？”
- 旁白只交代“谁、在哪、干了什么”，一条不超过 40 个字。不要文艺比喻。
  - ❌ “港口上空是一块正在消退的淤青的颜色。”“这句话落在两人之间，像一枚不肯倒下的硬币。”“同一张收据。”
  - ✅ “雨越下越大，窗户被砸得噼里啪啦响。”“Theo愣了一下，没接话。”
- 人物动作一律用**第三人称**写进旁白或动作：`["theo","act","Theo把外套往吧台上一甩。"]`，**不要**写“我把外套……”。
- 读者在任何时候都要知道：现在几点、在哪、谁在场、正在发生什么事、Nico心里在纠结什么。宁可直白，也不要让人猜。
- 每个人物有辨识度：Theo嘴贫爱抢单、一紧张就开玩笑；Wren八卦、护着Nico、爱拿录音笔；Mason话少、嘴硬心软；Ethan年轻冲、一身倔；Rowan冷静、像大哥、偶尔一句扎心话。
- 英文同样要自然地道，像美剧对白，不是中文直译；事件和顺序与中文完全一致。

## 二、文件格式

每个场景一个文件：`content/deep/afterhours_ch1_s<N>.json`

```json
{ "beats": { "zh": [ ... ], "en": [ ...同样的顺序和结构... ] } }
```
（第 5 场还要有 `"then": {"A":{"zh":[...],"en":[...]},"B":{...},"C":{...}}`）

**第一条必须是场景切换**：`["sys","scene",{"img":"afterhours/s1","place":"半月酒吧 吧台","time":"周五 晚上10:40"}]`（英文版 place/time 写英文，img 相同）。

普通句子 `[who, kind, text]`：
- `["n","act","旁白"]`
- `["theo","say","台词，不加引号"]`
- `["theo","act","Theo把杯子推过来。"]`（第三人称）
- `["nico","think",...]` **禁止**——Nico 的话和心理只能通过“轮到你”的选项出现，或者用旁白写“Nico心里一紧。”

**连续的旁白/动作会被自动合并进一个框**，所以可以连着写 2–4 条旁白/动作，再接台词。

停顿互动（stop）`[who, kind, {...}]`：

| kind | 写法 |
|---|---|
| `line`（轮到你） | `["nico","line",{"hint":"一句话说明此刻的处境/该怎么回","opts":[{"k":"say|act|think","t":"Nico说的话或做的事","then":[2–4 条别人的反应],"love":-3~3,"set":"可选的标记名"}, ...2–3个]}]` 选项要真的不一样（比如：嘴硬 / 真诚 / 打岔），反应也要不一样。`love` 只影响 Theo 的好感。 |
| `gift` | `["theo","gift",{"who":"theo","hint":"为什么此刻适合送东西","by":{"coffee":[...],"flower":[...],"hoodie":[...],"letter":[...],"ring":[...]},"then":[],"skip":[...]}]` 五种礼物：咖啡、一枝玫瑰、你的卫衣、手写信、戒指（没压力），每种 1–3 条贴合此刻的反应。 |
| `photo` | `["theo","photo",{"cap":"照片说明（带时间）","prompt":"英文生图提示词：场景、光线、人物外形、动作；不写名字；成年人；不要文字","then":[],"skip":[]}]` |
| `game` | `["mason","game",{"k":"remember","hint":"把游戏写成剧情的一部分","then":[...],"skip":[...]}]` 本章只用 `remember`（谁记错了：Mason和Ethan对同一晚的说法不一样，找出谎言）或 `order`（他点的那杯）。必须写 `"pair":[a,b]` 指定游戏里的两个人：`remember` 用 `["mason","ethan"]`；`order` 用 `["nico","theo"]`（游戏文案是“a 正在替 b 点单，4 秒记住它”）。 |
| `voice` | `["theo","voice",{"who":"theo","txt":"语音内容 1–3 句","hint":"为什么有这条语音","then":[],"skip":[]}]` |
| `call` | `["nico","call",{"cid":"来电人id","hint":"…","lines":[["来电人id","…"],…5–8句],"then":[...],"skip":[...]}]` |

**App 自带玩法（必须串进剧情）** `feature`：打开 App 里真实的玩法界面，玩完自动接剧情。
`["theo","feature",{"k":"snap|quiz|lie|heart|bottle","cid":"theo","hint":"为什么此刻要玩这个（写成剧情）","win":[玩得好之后的 2–4 句反应],"lose":[玩得不好之后的 2–4 句反应],"skip":[跳过时的 1–2 句]}]`
- `snap` 拍立得：和 cid 拍四连拍（固定算 win）。
- `quiz` 默契问答：5 道二选一，猜中 3 道以上算 win。
- `lie` 两真一假：猜出 cid 的那句假话算 win。
- `heart` 心跳测试：让 cid 心跳到 150 以上算 win。
- `bottle` 转瓶子真心话大冒险：转到谁就问谁，固定算 win（反应要通用，别依赖具体问题）。

**大事件卡** `["sys","event",{"icon":"⚡","title":"短标题","txt":"一句话"}]`：剧情急转直下的瞬间用（有人推门冲进来、停电、重大坦白）。全屏醒目卡片。每场 1–2 个。

条件分支（让之前的选择真的有影响）：
- 选项里写 `"set":"hinted_stay"` 给读者打标记。
- 之后用 `["sys","if",{"cond":{"flag":"hinted_stay"},"then":[...],"else":[...]}]` 走不同剧情。`cond` 也可以是 `{"love":["theo",20]}`（Theo好感≥20）或 `{"any":[...]}`。

## 三、本章长度与节奏

- 用户要求“一章能玩一个小时”。本章分 5 场，**每场 110–140 句**（含选项后的反应），每场约 12 分钟。
- 每场至少 **5 个“轮到你”**，并且至少要有一处冲突升级、一处让人笑、一处让人心里一酸。
- 不要注水：每 10 句左右就要有新信息、新冲突或新笑点。

## 四、人物与背景（全章通用，不能写错）

- 半月酒吧：渡口街的小酒吧，Nico 是合伙人兼调酒师（另一个合伙人是老周，今晚不在）。今晚提前一点打烊，专门给 Theo 办送别局。
- **Nico**（你，27，男）：嘴快、爱张罗、什么场面都能接住，唯独在 Theo 面前怂。大学话剧社认识 Theo，暗恋他五年，从没说过。只有 Wren 知道。**今天零点是 Nico 的生日**——他自己都忘了，也从来不跟别人提。
- **Theo**（30，男）：话剧演员，拿到纽约一部话剧的主演，**明早 7:10 的飞机，合同一年**。爱热闹、嘴贫、总抢着买单。其实他也一直在犹豫要不要去（这件事只有室友 Rowan 隐约知道）。他也暗暗在意 Nico，但从没表现得太明显。**第六张账单是他付的**（本章最后揭晓）。
- **Wren**（28，女）：Nico 大学最好的朋友，做深夜情感播客《打烊电台》，今晚想录一期“送别特辑”，录音笔一直开着。护着 Nico，一直暗中撮合。
- **Mason**（26，男）和 **Ethan**（25，男）：业余冰球队队友兼室友。上周 Ethan 膝盖受伤还想硬上决赛，Mason 偷偷告诉了教练，Ethan 被按在替补席，球队输了。两人冷战一周。其实互相喜欢，谁都没说。
- **Rowan**（29，男）：医院夜班护士，Theo 的室友，刚下班赶来。冷静靠谱，像大哥。
- 天气：暴雨红色预警。

## 五、第 1 章《第六张账单》分场大纲 v3（周五 22:40 → 周六 00:05）

用户反馈：剧情要**跌宕起伏、爽点多**，每场都要有“急转/反转”和“爽”的时刻，结尾必须是钩子。下面每场都标了【反转】【爽点】【钩子】，必须写到位。

**第 1 场 · 送别局（22:40–23:00，img `afterhours/s1`，半月酒吧 吧台）**
在场：Nico（吧台后）、Theo、Wren、Mason、Ethan。**Rowan 还在医院值班，第 2 场才冲进来**（大家提到他“下了班就来”）。账单：今晚 Theo、Wren、Mason、Ethan 各开了一张，加上 Rowan 提前打电话让 Nico 记在他名下的一张，一共应该五张——可打出来是六张。
开场 3 句旁白交代：今晚给 Theo 送行，他明早 7:10 飞纽约；你是 Nico，喜欢他五年。派对很嗨：Theo 站椅子上挨个损人（笑点密集）。Wren 起哄玩 **`feature quiz`（默契问答，cid theo）**：“谁最懂 Theo？”——win：Nico 全答对，全场起哄，Theo 愣住看他（【爽点】）；lose：Theo 笑他“五年白认识了”，Nico 心里一酸。Wren 把 Nico 和 Theo 推进角落的拍照墙：**`feature snap`（拍立得，cid theo）**。Mason 和 Ethan 坐吧台两头互不说话（埋线）。
【反转】Theo 举杯宣布：“还有件事——纽约那边要签我五年。我不回来了。”全场安静（`event` 卡：💥 他不回来了）。至少 2 个“轮到你”回应这句话（强颜欢笑 / 当场怼他“你倒是早说” / 转身去倒酒）。
【钩子】Nico 去打结账单：一共六张，可今晚只开了五张；第六张已付，签名只有一个“T”，留言被折着还没看——闪电，所有人手机同时尖叫：暴雨红色预警（`event` 卡）。

**第 2 场 · 走不了了（23:00–23:20，img `afterhours/s2`，临街窗边）**
地铁停运、机场高速积水，Theo 刷航班：“暂时正常”。【反转】门被撞开（`event` 卡：🚪 有人冲进来）——是 Rowan，浑身湿透从医院赶来：“外面全淹了，谁都别走。”他看 Theo 的眼神很怪，像有话要说。
【冲突】Ethan 要冒雨走回家（膝盖还肿），Mason 堵门，两人当众吵翻：Ethan 当着所有人吼“是你告诉教练的！你凭什么替我做决定！”（轮到你：劝架三选一，各有后果）。
**`call`（cid wren）**：Wren 躲进洗手间给 Nico 打电话：“他说不回来了你听见没？你还要憋到什么时候？”（好笑又扎心）。
**`game order`（pair ["nico","theo"]）**：Theo 让 Nico 调“老样子”：“你要是还记得我每次点什么……”
【钩子】Theo 小声问：“说真的，你觉得我该去吗？”——地下室传来哗啦一声巨响，水冲进来了。

**第 3 场 · 地下室（23:20–23:40，img `afterhours/s3`，地下室楼梯口）**
水漫到第三级台阶。Rowan 指挥，Mason 和 Ethan 被迫一起抬酒桶（吵着架步子却完全一致，笑点）。Nico 和 Theo 在最里面打手电搬箱子，只有他们俩。
Theo 再问那句：“你觉得我该去吗？”——本章关键选择（`set` 分别是 `told_go` / `hinted_stay` / `joked`，Theo 反应截然不同）。
Theo 冻得直打喷嚏 → **`gift`**（卫衣最自然）。**`feature heart`（心跳测试，cid theo）**：黑暗里 Theo 往前凑了一步，手电光里两人离得很近——win：Theo 心跳得比 Nico 还快，被抓包（【爽点】）；lose：Theo 先退开，笑着打岔。**`photo`**：手电光下两人站在水里。
【反转】Theo 刚开口：“Nico，其实我不想——”——`event` 卡：🔌 全店停电。【钩子】黑暗里有人抓住了 Nico 的手腕。

**第 4 场 · 真心话（23:40–23:55，img `afterhours/s4`，烛光下的吧台）**
抓手腕的是 Theo，灯一亮（蜡烛）他立刻松开，装没事（用 `if` 按 told_go / hinted_stay / joked 写 Theo 的不同态度）。Wren 掏出酒瓶：**`feature bottle`（转瓶子，cid theo）**。
**`game remember`（pair ["mason","ethan"]）**：Wren 让 Mason 和 Ethan 各讲“膝盖那晚”，说法对不上。
【爽点】Mason 终于爆发：“对，是我说的！因为我宁可你恨我，也不想看你废一条腿——因为我喜欢你！”全场炸了（`event` 卡：💥 Mason 当众表白）。Ethan 愣住，抓起外套冲向门口又停下……
轮到 Nico 抽到真心话：“在场有没有你喜欢的人？”（撒谎 / “有，但我不说是谁” set `truth_half` / 反问 Theo）。
**`voice`**：Wren 的录音笔翻出 5 年前话剧社谢幕那晚的录音：喝多了的 Theo：“以后不管我去哪儿，Nico 的酒吧我都会回来喝。说好了。”【钩子】Theo 听完，起身走开了。

**第 5 场 · 第六张账单（23:55–00:05，img `afterhours/s5`，收银台 应急灯）**
大家散在各处（Ethan 和 Mason 坐在楼梯上，隔着一个台阶，谁都没走）。Nico 一个人对账，打开第六张账单的留言：“给N：五年了，每次都是你请。这次换我。生日快乐。——T”。零点，手机弹出生日提醒——他自己都忘了，全世界只有 Theo 记得。
【反转】Rowan 走过来，压低声音：“他根本没签那份五年合同。他跟我说，在等一个人开口留他。”——`event` 卡：📄 合同还没签。
Wren 凑过来问怎么了；Nico 内心挣扎（至少 5 个轮到你）。**`photo`**：应急灯下那张账单和留言的特写。用 `if` 让之前的标记影响 Theo 远远看过来的一眼或一句话。
最后停在本章选择：“这张账单，你打算怎么办？”不要替读者选。
再写本章三个选择之后的剧情 `then`（每个 15–25 句，至少一个 stop，结尾都是钩子：地下室的水又涨上来了 / Theo 的航班状态变了）：
- A 拿着账单当面问Theo → Theo承认是他付的，也承认一直记得Nico的生日。两人之间的气氛变了（停在欲言又止）。
- B 先揣进口袋，装作没看见 → Nico把账单悄悄收进口袋；Theo看见了，也什么都没说（停在一个失落的眼神）。
- C 当着所有人念出来 → 大家才知道今天是Nico生日，热闹地给他庆祝，Theo却躲进了后厨。

## 六、完成标准
运行 `python3 content/deep/validate2.py afterhours 1 <场次>`，直到输出 `OK ✓`。
