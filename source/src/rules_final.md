01｜生成职责与规则优先级
生成范围、事实状态和规则强度先明确，再进入具体内容。

本文规定互动剧本的架构、人物、章节、玩法、分支与逐场生成要求。按实际任务选择生成层级，各阶段共享同一套世界、人物与状态依据。
执行优先级：本次用户明确要求 > 当前已确认项目设定 > 本文硬规则 > 项目模式配置 > 建议默认值。必须／不得为硬规则；建议／默认及未被用户明确锁定的数量参数可调整。单本有效游玩24小时以上、全本15—20章为已确认的容量与章节范围；具体章数在范围内确定，单章预算、阶段配比、回合数及句长仍为可调建议。
区分已确认设定、生成提案、待确定输入；缺少非关键字段可采用明示假设，关键字段缺失时只询问必要信息，并完成不依赖答案的部分。不得以猜测覆盖事实。
只输出请求的层级；未要求正文不写正文，未要求验证时，不额外生成测试样板、验收流程或运营方案。结构条件与引用完整性属于生成规则，不代表已运行验证程序。
本框架统一覆盖长篇容量、章节厚度、互动玩法、世界展开和海外对白表达；架构、人物、玩法、正文与本地化阶段读取同一份生效设定，对白要求贯穿架构、场景及逐场输出。
内容厚度来自有因果的新经历、人物变化、世界反馈和有后果的参与；单句精简不等于删减经历，长篇时长不以增加赘述或重复聊天实现。

03｜生成顺序与模块依赖
先完成上游依赖，再细化场景与表达；正文中的新信息必须回到共同设定中。

先定义“玩家通过何种参与获得何种感受”，再确定核心事件、关系问题、人物弧光与四轴结局方向，倒推阶段目标和可达路径。
生成顺序：定位、24小时以上容量口径与世界边界 → 完整人物画像及长线问题 → 结局方向 → 阶段／章节与互动预算 → 世界信息及认知情绪链 → 分支、状态与道具路径 → 场景与节拍 → 信息权重与对白／画面分工 → 对白、演出及本地化 → 回填状态、记忆、时长估算与结局资格。允许回调，回调后同步更新依赖项。
Cold Open 优先通过具体行为呈现角色吸引力、对玩家的态度和首次有效参与，同时交代我是谁、在哪里、眼前发生什么。约2分钟仅为体验参考，不强制以危机开场，不虚称已满足精确演出时长。
开篇突出一个核心吸引点及一个待探索侧面，用对待玩家、他人、拒绝、失误和利益取舍的行为表现为人，不以标签堆砌代替展示，不一次交代全部优点与秘密。
每阶段必须有可感知变化；每场有具体目标或相处内容、行动／回应空间及退出状态。章节可通过冲突、理解、兑现、愿望、邀请或生活进展推进，不强制每章反转、争吵和悬崖钩子。
时间轴、人物动机、秘密、承诺及行为后果持续一致；关键剧情可回溯到事实、节点、选择和状态，不能临时改规则迁就结果。
事件线、关系线、人物弧光线分别记录并相互影响；与谁调查、合作或战斗，不自动等于与谁恋爱。不得先生成大量对白再反推结构。
故事需要可延展的主问题、阶段问题、人物关系问题与世界中的利益／价值矛盾。长篇不能把同一个误会反复拖延，也不能靠结局前临时新增真凶或设定延长篇幅。
开篇先交付人物吸引力，随后以实际参与逐步扩大世界与问题；“世界厚”不等于开篇集中讲历史，“对白短”不等于整段经历只剩摘要。
04｜世界边界与角色优先开篇
作者端建立完整因果，玩家端先见人、先能参与，再随着行动理解世界。开篇的具体交付见第03节，世界展开遵循以下要求。

作者端定义足以支持剧情因果的固定事实、制度、能力与限制；玩家端按需呈现。少讲世界观不等于后台设定不完整。
世界类型、生活基调、玩家身份、初始关系及影响相处的关键限制，在介绍页或开篇说明；当前行动所需的规则、代价与风险，在玩家选择前提供；历史、组织、文化和深层秘密按行动及主动询问逐步展开。
熟悉的已有世界简短定位时期、地点、身份、关系与重要改写；陌生原创世界从可理解的局部生活切入。提供可选背景，不假设所有玩家都熟悉原作。
以行动、环境、价值分歧和询问带出背景，解释方式符合角色语言习惯；世界讲解不得长时间中断首次人物互动。
世界厚度至少覆盖与本故事有关的可生活层面、社会规则、利益／权力关系、历史成因和未来变化。按题材选取家庭、学习／工作、公共与私人空间、组织、资源与文化等，不为凑规模增加无关势力或术语。
每项重要规则关联生活中的具体表现、影响的人物、受益／受限者、玩家可参与的方法、选择代价与后续反馈。背景设定只有真的改变相处、行动或理解，才进入当前章节。
世界按“局部体验—规则实际生效—不同人物立场—历史或秘密成因—玩家行动后的变化”逐步加深；这是可调整的展开链，不强制每项设定按同一顺序揭露。
同一地点与活动可以回访，但人物、线索、关系用途或可行动内容应随阶段变化。资料库可提供可选深入了解，当前选择必需的规则不能只放在可跳过的资料库。
支线人物有自身目标、立场与行动后果，组织和世界不会只为主角服务；推进仍受时间、资源与知情约束，不把每个配角都写成恋爱障碍或讲解员。
明确时间推进带来的局部变化及回访状态，不把“现实隔一天上线”直接解释为故事已自动跳过关键事件。
05｜人物母档、数值与弧光
人物不是属性清单的堆叠。画像应能解释角色在不同压力、知识和关系下为什么这样说、这样做。

主要人物具备：外形与身份、经历、能力与限制、喜恶及具体偏好、习惯与口头禅、语言节奏、欲望、弱点、恐惧、秘密、压力触发点、三观与价值排序、自我认知及实际矛盾、亲密边界、关爱方式、冲突与修复方式、主动目标、成长阻力及变化后仍保留的特征。
分开维护稳定画像、当前状态、对各人的关系档案及长期弧光档案。支持玩家与AI角色双向设定：玩家固定背景、可塑造行为和暂时推断分开；角色对不同人的态度分别有依据。
行为推导：画像依据 + 知情范围 + 情境压力 + 关系阶段 + 弧光阶段 → 解读、回应与行动。重要特征配置触发行为、条件、即时反馈、数值效果、记忆、延迟后果、修复与重复规则；装饰性偏好不必全部机制化。
角色可以主动分享、提出方案、拒绝、解释、道歉或退出，具有独立生活和目标并承担代价，不成为讨好机器；道具和付费不能取消底线。
每名角色仅使用亲历、被告知或能够合理推断的信息；客观真相、玩家已知与各角色已知分开，不能读取全局未解锁真相。推断不是已证实事实。
数值建议从每名主要角色2—3项关系指标及1—2项弧光指标起步，定义初值、范围、增减依据、单次／单场上限、重复递减、可见性、读取点及回溯处理。好感、信任、尊重、临时情绪和重大事件分别记录。
弧光按“起始模式—动摇—尝试—考验—稳定或转向”组织；推进、停滞和退化须有情境、经历与行为证明。普通聊天或送礼不能抵消背叛、违约、越界或跳过关键考验，不因漏聊一次直接退化。
快速建立兴趣、安心、欣赏或张力，亲密程度仍符合初始关系；旧友、恋人、宿敌有共同历史依据。不得代替玩家决定爱上、原谅、同意亲密或接受关系；角色误解只能记为角色理解。
人物母档补充持续生活、跨章目标、关系阶段的不同相处内容及可反复检验的价值矛盾；人物深度由多情境中的一致选择与真实变化构成，不靠增加设定标签或反复暴露同一创伤。
为各目标语言维护人物声线卡，并与章节知情、关系阶段及情绪状态联动；直接表达的强度符合当时关系，不为句短而抹掉性格，也不为长篇而长期拖欠已到时点的情绪兑现。
06｜长篇容量与章节设计
容量按一名玩家的可达体验估算，章节按完整问题与相处经历组织。两者不能用分支文本总量或空泛聊天长度替代。

6.1 容量口径与初始预算
单个本子以一名玩家在一条可实际完成的普通完整路线中获得24小时以上有效游玩为容量目标。完整路线可以分多次进入，不要求连续在线；拒绝参与、主动提前结束与早期失败路径单独说明，不用于代表完整体验。
统计玩家实际可经历的阅读、实际演出、判断与输入、探索、协作、关系互动及有目标的自由交流。互斥路线不能相加；重复读档、重复素材、现实离线、加载／模型等待、挂机、强制等待与无新内容的无限聊天不用于填充目标。
分别列示普通完整路线、提前结束、路线独有、可选活动、付费独有与重玩新增内容。按实际可达和可获得范围估算，不将未购买、互斥或未实现内容计入该玩家的体验；商业版本不同则分开列示，不据此擅自改变既有付费规则。
全本统一章节目录控制在15—20章，章内展开分支与子场景，不将每条分支再各增一套独立章数。建议初始预算为18章、每章平均约90分钟，合计1620分钟／约27小时；18章与90分钟为可调起点，不是已锁定的项目配置。以24小时下限反推，15章需平均96分钟／章、18章需80分钟／章、20章需72分钟／章；实际分配允许长短错落，时长仍须由内容支撑。
18章初始阶段分配可采用第一幕4章、第二幕上5章、第二幕下5章、第三幕4章；中点位于第二幕内。此为范围内的预算示意，章节数不等于结局数量；选择15—20章中的其他规模时按阶段功能重新分配，不把各路线章节相加作为统一目录章数。
长章节建议分为4—6个可自然中断的段落，单段可从15—25分钟的设计预算起步；例如18章方案中每章5段、每段约18分钟，对应约90分钟。段落可按内容调整，形成小目标、变化和继续入口；不要求一次玩完整章，退出与返回延续已提交状态。
有效时长按具体路线上的非重叠内容单元累计。文本阅读可用目标语言实际字／词量除以明示阅读速度估算；配音与同步阅读不重复相加；决策、输入和非文本玩法分别估算，所含文本或演出已计过的部分不能再次累加。
先给出路线分钟预算，再回填可实现的场景、互动、文本与演出。单列所有分支的总生产量，用于创作规划；它不等于一名玩家的游玩时长。
达标依据是可达内容与可解释的估算，不是章数、字数或聊天上限的单项数字。只有最长路线达标而普通路线明显不足时，须明确差异并补容量或调整适用口径，不以最长路线代表全部玩家。
容量不足时增加有功能的经历、阶段问题、角色互动、世界行动与后果回收；不得通过复读、无意义跑腿、机械失败重试、无限刷数值或故意缓慢显示文字凑时长。
24小时以上是内容规划目标，不宣称所有玩家在快读、跳读或不同输入习惯下都必然停留相同时间。未进行真实游玩时记录estimated，不写measured，容量规划不等同测试或验收结论。
6.2 章节厚度与可中断体验
每章先定义玩家为何愿意参与、想完成或理解什么、角色为何在场、当前世界规则如何影响行动，以及结束后发生什么变化，再分配场景、互动与分钟预算。
每章通常承担事件推进、关系变化、人物弧光、世界理解中的至少两类内容功能；这是防止空章的编排建议，专门的缓冲章或兑现章可以集中承担一类功能，但须有明确价值与后续承接。
章节厚度通过场景之间的因果形成：信息或相处引发判断，判断带来行动，行动改变处境，人物回应后果，再决定下一步。不能把连续几十段对白或互不相干的小活动当作厚度。
普通完整章节应有完整体验单元，而非只有起因和悬念。允许以阶段结果、小承诺、问题重释、计划推进或关系变化形成收获；不要求每章解决全部冲突。
同一章的有效互动可分布在方法选择、探索或协作、自由表达、后果判断与角色回应中；不是只在章尾弹一次选项，也不要求每句对白都可分叉。
主线活动、日常相处与自由交流共享时间、场景、人物状态与记忆；相处内容可以回应刚发生的事件，也可以承接角色自身生活，不成为与主线无关的闲聊填充包。
章节卡必须包含chapter_id、阶段与路线、进入状态、体验承诺、核心问题／相处目标、事件／关系／弧光／世界功能、可中断段落、场景序列、互动机制、关键选择、信息释放、情绪兑现、退出状态、回访承接及非重叠时长构成。
章节结束时保留明确的已完成、仍开放、承诺／未修复冲突和下一步空间；回访用简短、与当前行动有关的承接帮助恢复状态，不每次重讲整章。
章节内容量与可用演出／玩法能力匹配。尚未具备的玩法和资产标为proposal或需求，不能写成已经可玩；批量生成时保持前后章节依赖，不为凑章数复制同一故事模式。

全本章数	按24小时目标反推的单章平均容量
15章	96分钟
18章	80分钟
20章	72分钟
上表仅为总容量除以章数的预算关系，不是已实现时长。建议起点18章×90分钟约为27小时；每章可以由多个短段落分次游玩，时长需要由阅读、互动、探索、相处与实际演出共同支撑。

07｜纵向阶段与树状分支
三幕组织问题如何变化，阶段内分支组织玩家如何参与；二者相互嵌套。

总结构：纵向阶段主干 + 阶段内树状分叉 + 带状态汇合 + 少量独立高潮路线。禁止把三幕式等同单线剧情，禁止无预算的全组合树。
七层单位：整部故事 → 幕 → 阶段／章节群 → 路线 → 场景 → 节拍 → 交流回合。章节为阅读组织单位，不要求一章只有一个场景或一条路线。
第一幕建立角色吸引力、参与理由、关系问题及首次有效行动，以承诺、代价或主动卷入进入第二幕；不自动锁定恋爱对象。
第二幕上开放不同方法，形成独有经历、信息、资源与关系差异；中点通过新认知、合作变化或代价改变问题性质，不强制惊天反转。
第二幕下兑现早期选择与延迟种子，检验人物弧光、承诺及未修复冲突，提供最后转线窗口；第三幕进入实质不同的高潮，承担后果并结算四轴结果。
有限主线初始比例可用20%／30%／30%／20%；区间参考为15%—25%／25%—30%／25%—30%／15%—25%，实际合计100%。按一条典型可玩路径估算，中点包含于第二幕，不按所有分支文本总量计算。
持续陪伴采用“建立相处—共同经历与理解变化—阶段性兑现”的局部周期，不强塞终局危机；混合型主线之间保留日常空间。
阶段卡填写：stage_id、共同问题、进入条件、可选方法、独有体验、失败后果、汇合条件、保留状态及下一阶段变化。方法数建议2—4种，拒绝、绕行、有限配合可以是有效方法。
阶段卡补充该阶段的章节范围、可达分钟预算、主线与关系推进、世界展开目标、核心互动组合、种子种下／回收点与中断入口。幕比例与长篇容量一起配置，不能用比例代替具体内容。
长篇阶段内安排不同强度和性质的经历，允许连续合作、平稳相处与阶段性胜利；节奏通过问题和关系的变化形成，不每章强制升级危机。
7.1 阶段职责
阶段	应形成的变化	18章预算示意
第一幕	建立角色吸引、参与理由、当前问题及首次承诺／代价	4章
第二幕上	不同方法带来独有经历、知识、资源及关系差异	5章
中点	重新理解事件、动机、合作或代价，改变下一步问题	包含于第二幕
第二幕下	早期选择兑现、弧光受考验、转线窗口与高潮资格收束	5章
第三幕	在实质不同的高潮中行动、承担后果、完成四轴结算	4章
章数分配是起点。调整后仍需满足15—20章范围、阶段因果与24小时以上容量目标。

08｜互动玩法与参与循环
互动机制应让玩家实际观察、判断、表达、协作和承担结果，并持续改变当前体验。

先为每个本子确定少量可持续变化的核心互动循环，建议从2—4类起步；再结合题材选择局部玩法。核心循环可采用“观察／了解—表达意图—行动或合作—角色回应—状态与新内容—后续承接”。不要求所有题材使用相同机制。
可选机制包括线索观察与比对、场景探索、信息与证词判断、方法／日程规划、合作活动、对话协商、关系边界与承诺选择、有目标的自由交流及符合世界的轻量小游戏。只采用服务人物与剧情且平台可支持的机制，不把清单全部塞入每个本子。
每项机制写清叙事目的、适用章节、参与人物、可用输入、进入条件、动作空间、反馈、相关状态、信息知情、结束条件、失败／退出替代及后续读取点。
玩家参与应改变信息、方法、资源、承诺、关系体验、可用行动或后续结果中的至少一项。纯欣赏性活动可提供独有相处与记忆，不强制每次产生数值收益，也不把所有活动设计成胜负挑战。
同一机制复用时，通过对象、条件、合作方式、人物态度、已知信息与代价变化形成不同体验；只换措辞和皮肤的重复操作不计作新内容。
自由交流可支持当前目标的讨论、角色自身生活及共同记忆的推进，也允许自然闲聊与停留。计入容量的预备内容需有可描述的话题／活动范围、阶段变化和承接，不以“模型可无限回答”代替内容设计。
玩法选择与人物弧光关联：同一问题可因角色价值观、能力、压力和关系出现不同协作与解法；解锁与拒绝遵守事实和自主条件，不能单靠反复送礼跳过核心经历。
有失败可能的玩法写清可理解的规则和已知风险，提供符合题材的继续、替代或终止去向；不会某种操作不自动等于不爱角色，不以重复失败拉长游玩时间。
时长来自真实参与与内容反馈，不按点击数、必要等待、无意义重复或输入字数发放关系进度；选择少、表达短的玩家仍有可达的完整内容。
机制涉及道具／付费时按第14节处理，涉及自由行动与持久状态时按第18节处理；机制卡只声明所需能力，不擅自假定程序已实现。
09｜分支等级与选择契约
分支的跨度、拓扑、可逆性和剧情作用分别定义，避免用选项数量冒充有效参与。

可用拓扑：回折、挑战、时间洞穴、分支与瓶颈、嵌套分支。回折保留经历；挑战有明确目标与失败去向；时间洞穴式扩展限制深度与预算，选择是否不可逆及能否读档另外配置并说明风险；瓶颈不清零状态；嵌套服从路线预算。按需要选用，不要求全部出现。
分支等级：L0表达（1—2次回应）；L1关系微变化（1—3节拍）；L2场景分支（1场）；L3阶段路线（约2—5场）；L4跨阶段长路线；L5高潮／结局路线。跨度为参考，等级不等于拓扑。
实质分叉来自明确意图、累计行为、资源与事实、人物自主反应或弧光差异。一次模糊措辞不得锁定长路线；有歧义时澄清或保留未定。
L0可以只改变表达，不能假称影响命运；重要选择必须改变行动、信息、资源、参与人物、承诺、边界或后续机会，并配置可感知反馈和后文读取点。
状态至少分为：人格倾向 personality、关系 relation、剧情事实 plot、各人知情 knowledge、资源 resource、承诺 commitment、未修复冲突 unresolved_conflict、记忆 memory、时间 time。短暂情绪不直接改写稳定人格。
选项契约：id + text + choice_level + player_intent + visible_if + enabled_if + risk_notice + immediate_feedback + effects + seeds + exclusive_experience + delayed_payoff + merge_carryover + reversibility + route_switch + fail_forward + next_node + route_map。不适用填无；显示条件与可执行条件分开，重大不可逆风险提前说明性质。
延迟种子契约：seed_id + create_at + create_if + payload + knowers + evaluate_at + trigger_if + repair_if + expire_if + outcome + consumed_if。无修复路径明确写不可修复；无触发时有继续等待、到期失效或替代去向。种子不重复兑现，后果关联实际来源行为。
L4长路线写清入口、独有目标、持续内容、转线窗口、锁定点与退出后果；转线可以有代价，是否可回溯预先定义，不用无限重试替代失败设计。
分支明确即时回流、阶段汇合、跨阶段延迟兑现或独立终局。汇合读取到达方式、证据、资源损失、在场人物、各人知识、承诺、未修复冲突、弧光及玩家边界；用共同骨架、条件片段和独有场景承接，核心目标或主要对手已不同时不强行汇合。
结构完整性要求：节点引用有效、路线入口与退出明确、关键路线有可达条件、主线不死循环、重复活动有退出与去重规则、汇合保留反馈差异、结局触发链及回溯点完整。未定义路径不得自动进入BE；未运行工具时不声称检查已通过。
长篇路线预算分别记录共享章节、独有场景、条件片段和独立高潮；汇合用于复用共同问题，不能把24小时目标解释为所有分支各写一套同长度文本。
每条普通完整路线关联其章节／场景序列、可获得内容及独立时长估算；路线转移读取此前经历，不将已经玩过的共享场景再次计为新增时长。
9.1 分支分级速查
等级	主要作用	参考跨度
L0	表达、语气、即时氛围	1—2次回应
L1	记忆、边界、称呼和相处变化	1—3节拍
L2	方法、信息、参与人物或代价	一个场景
L3	完整阶段方法与经历	约2—5场景
L4	跨阶段持续改变目标与经历	多个阶段

表达分支可以只改变表达；重要选择必须有可感知后果及后文读取点。汇合复用共同问题与场景，不清除经历。

10｜场景、交流回合与节奏
场景先有具体作用与退出状态，再写对白。节拍以信息、理解与策略变化形成，不以固定行数强制制造冲突。

先设计场景目标、阻碍或微张力、玩家行动空间、人物策略变化、退出状态及后续读取点，再写对白；“推进关系”不能独自充当场景目标。
张力可来自目标、方法、价值、信息、边界、资源、时间、内在矛盾及期待。日常允许无对抗，但有具体相处内容和连续性，不机械制造争吵。
1交流回合 = 玩家一次有效输入／选择 + 角色及系统完成一次回应与结果反馈。节拍由信息、障碍、理解或策略变化形成；重复发送、格式修正和无效输入不重复产生收益。
强剧情参考：3—6回合留意停滞，8—15回合完成主要选择或自然收束，可每1—2场出现强冲突；混合参考：5—10回合有事件／关系变化，12—22回合形成场景收束，可每2—4场出现中高强度冲突；日常参考：8—15回合留意新鲜变化，16—30回合完成相处／活动，不设置强制争吵频率。
固定VN文本可参考每节拍6—14条、每场24—60条短对白。全部回合与行数仅为创作提醒，不能充当运行时自动打断聊天或强制翻脸的计数器；自然完成可提前收束，愿意停留可延长。
同时管理事件、关系、认知、情绪强度和玩家主动性。强冲突按“积累—触发—应对—后果—缓冲”展开；中高强度事件及反转后留出判断、回应、修复或休息空间，不用连续刺激覆盖情绪。
交流回合与短对白长度服务单个节拍，不直接决定整章或全本时长。长章节由多个相互承接的场景、互动与余波组成；不能把原有短场景字数上限机械套成一章全部内容。
长篇节奏交替安排高／低信息、高／低情绪及不同主动性，重大选择与反转后留出回应。低信息段仍可有具体相处与人物生活，不等于空白等待。
信息权重、显示单元、短句、对白／画面／旁白分工和本地化共同采用第13节的表达规则；正文精简不改变本章已经定义的经历、玩法与后果。
11｜长线连续性与跨章承接
长篇依赖可追溯的状态、伏笔和人物生活；回访与重释提供新意义，避免每章重置。

为24小时以上内容维护阶段账本：时间、位置、角色当前目标、在场与知情、关系和弧光阶段、资源、未兑现种子、承诺、未修复冲突及玩家边界。
长线问题分配起因、不同阶段的变化、玩家可参与节点、代价和回收位置；旧问题产生新行动或理解，而不是仅换人物重复同一争执。
伏笔与反转跨章配置，标记种下、强化、异常线索、判断窗口、揭晓与余波；同一事实可多次被重释，但不因篇幅延长无依据改写历史。
角色变化需要跨情境的行动证明；早期改变会在后续压力中被检验，已形成的稳定习惯也能持续产生内容，不把每次新章写成人设重置或关系退回初识。
回访同一话题、地点或活动时读取共同经历与新状态；重复是为了回响、修复或变化，不重复发问、重复奖惩与重复告白来填章节。
中断后恢复已提交状态，必要时提示当前小目标与未完成事项，不泄露未取得线索或其他路线；章节更新与存档迁移按第18节的版本规则处理。
长篇结束前按已定义条件回收核心问题和关键承诺；开放目标可以继续，但不能用“以后还有内容”代替本段应有的结果和情绪兑现。
12｜认知分层、反差、反转与情绪兑现
玩家看到什么、如何判断，以及之后如何行动，需要分别编排。情绪兑现既有长线积累，也应有局部落点。

12.1 事实、推断与反转链
分开记录 objective_truth（客观事实）、observations（实际可见信息）、testimonies（人物叙述）、belief_options（玩家可能推断）、intended_emotion（预期情绪）。未表达的推断与情绪不得写成玩家必然想法和感受。
人物反差由共同的价值观、欲望、恐惧或经历解释，用于吸引、暴露代价和弧光考验，不随机拼贴互相矛盾的标签。
重要情绪线建立“承诺—具体积累—受阻／偏差—玩家判断窗口—重新理解—行为兑现—关系余波”。受阻可以是未说出口、未被理解或现实限制，不必反复背叛与伤害。
反转前布置支持表面解读的线索及与真相一致的异常线索，重大反转可增加主动核验路径；揭晓前允许询问、调查、保留判断和提出推断。玩家提前猜对要承认，不强行重置为受骗。
连续反转可沿事实、责任主体、动机、价值及关系逐层深入；后一次增加意义或因果，不能无依据“A真—A假—A又真”。不能澄清误会时必须有实际限制与代价。
微反转至少影响认知、情绪承诺、关系、事件行动、弧光中的两项；中反转至少三项；主线大反转改变事件方向与关系，并影响弧光或结局资格。普通信息补充按揭露处理，不冒充大反转。
高反转档可按约10场配置4—6微反转、2—3中反转及1大反转作为起点；按一条可玩路径及最高等级归类，不重复统计嵌套反转。此为可调配置，不是通用门槛。高反转不等于高争吵、高伤害，日常以偏好发现、人物反差和关系重释产生丰富变化。
反转卡记录 twist_id、真相、表面解读、支持／异常线索、知情人、发现路径、判断窗口、揭晓版本、情绪承诺、事件／关系／弧光影响、残余冲突及后续节点。不同分支可以改变揭晓时间、视角和代价，不能随态度或支付改写真相。
揭晓后必须给玩家新的选择或回应空间；善意动机不抹掉伤害，听到解释不自动原谅、修复信任、完成成长或升级关系。
情绪线跨章积累与回收，同时在局部场景提供可感知的回应；不能为拉长全本时长把所有重要表达拖到结局，也不能靠每章更强的伤害维持刺激。
玩家可能推断与实际表达分开；世界、画面、对白与角色证词提供可解释的信息差，直接对白仍不能把证词自动变为客观事实。
12.2 留白与情绪节拍
留白用于让玩家形成判断、感受迟疑或选择回应，不用于遗漏当前行动所需的规则与风险。情绪可留空间，选择依据须清楚。
用具体情境、个人化细节、关系承接和有分量的核心句调动情绪，不靠连续堆叠“极其、深深、无比、温柔地、悲伤地”等强度词要求玩家感动。
高价值情绪句之后，允许一个简短动作、一次等待回应或自然换拍；不要立刻解释其意义、加入第二次表白或抛出新任务。不是每句短对白后都要停顿。
重要情绪可沿“具体触发—角色克制／动作—直接表达—玩家回应—后续行为”兑现；根据人设调整，不要求每场套齐全部步骤。
沉默必须有情境作用。省略号、破折号、空白消息和重复称呼不能代替真正的张力；不规定固定等待秒数或用拖延阻止阅读。
有意重复可用于节奏、语气反转、安抚或关系记忆；只有不增加意义的重复才删除。压缩后仍须保留热度、礼貌、幽默及人物的呼吸感。
13｜海外对白与信息呈现
表达层与结构层共用事实、知情、关系与行动边界。角色直接对玩家表达，画面补充可观察的差异，旁白只补必要信息。

13.1 信息权重与交付时点
为信息标记权重，再决定必须表达、延后表达、交给画面或删除；权重是编排依据，不在玩家界面显示标签。
P0 选择必需：当前目标、可行动范围、代价、关键限制、不可逆风险和相关条件。必须在对应选择前清楚交付，不靠隐晦措辞、俚语或细微表情承载。
P1 核心剧情与关系：当前阶段应揭晓的事实、明确表白、拒绝、承诺、边界与关系变化。优先由有知情与表达资格的角色直接说出；对白、证词和系统确认事实仍需区分。
P2 人物与情绪细节：习惯、克制、迟疑、反差和潜台词。优先通过有辨识度的措辞、动作、停顿、声音与画面补充，每个细节应服务当前相处。
P3 氛围与装饰：与当前判断、人物或场景作用无关的景物、修辞、重复解释与寒暄可删或移到后续。世界观信息本身不永久属于低优先级；影响当前行动时提升为P0或P1。
不以删字为由删去必要依据。角色不能知道的信息，不能为了交付P0／P1强行塞进他的对白；应由合法的证词、文件、界面或简短说明呈现。
13.2 信息饱和度与分拍交付
默认一个显示单元承载一个核心信息，必要时加一个直接支持它的信息。一次交付多个条件时分清关系，不将背景、解释、表白、反转与新任务堆进同一个文本框。
先提供当前必须理解的内容，再补相关原因。新术语、新人名与新规则分批出现，用明确指代帮助衔接；已经知道且未变化的信息不反复介绍。
普通交流允许“提问—回答—进一步了解”；重要揭晓、明确表白或高强度转折后，优先安排简短回应、动作或玩家参与空间，再进入新议题。
高信息场景降低额外修辞和无关动作；高情绪场景减少新设定与多重任务。高信息与高情绪同时发生时，突出真正要记住的核心句，再分拍交代其余内容。
不以数字控制玩家理解，不因到达几句或几个信息点就强制打断。用户一次问了多个问题，应完整回答或说明保留项，不以“一句一个信息”为由漏答。
关键线索允许在新的决策情境中短促回提；回提应带来用途、判断或态度变化，不能把必要回顾一律视作冗余。
13.3 角色直接面向玩家表达
表白、选择、承诺、拒绝、道歉与关键解释，应尽量让角色直接对玩家说。已进入表达与兑现时点的内容，不用“他似乎想告诉你……”或“你终于明白他的心意……”代替当事人的话。
角色对玩家说话时，使用符合目标语言与人设的直接称呼、指代和句式。不要把角色写成面向观众介绍玩家的解说员；也不要求每句强插you／我／你。
核心信息先有清晰落点，例如“I came back for you.”；画面可以表现他说这句有多难，旁白不再替这句解释“他很在乎你”。
直说不等于所有人物必须立即坦诚。回避、撒谎、反讽、嘴硬和未完成的表达可以存在，但必须有当前动机与可理解语境；不能用长期含混替代应有的剧情兑现。
保留玩家自主性。可以写角色表达“我想你”，不能擅自写玩家已经心动、原谅或接受；需要回应时提供真实的行动或表达空间。
角色说出的内容不自动成为客观真相或系统承诺。承认、猜测、保证、威胁和说谎分别保留其性质，不因改成直接对白就改变状态。
13.4 对白、画面与必要旁白的分工
对白承担说给玩家听的事实、态度、意愿、请求与承诺；画面承担可观察的动作、空间、视线、距离、物件和表里差异；旁白承担必须补足的时空、动作衔接与当前渠道无法清楚呈现的信息。
同一个意义不连续用“对白＋动作＋旁白解释”重复三遍。多渠道并用时提供互补信息，或用于有意强调的关键节拍。
画面可以与话语产生有依据的差异：角色说“你先走”，手却仍停在门边。让玩家察觉差异，不紧接一句旁白公布“其实他舍不得你”。
动作描写优先可见、具体、有意义的动作，例如“他把你的杯子移到暖气旁”；少用“眼里闪过复杂神色”等无法落实演出的泛化描写。
不把每句对白都配上微笑、挑眉、靠近、叹气和低声。只有改变理解、关系距离或节奏的动作才保留，避免重复同一套情绪动作。
只能调用实际支持的立绘、表情、动画、音效或镜头。缺少资产时标记演出需求，采用短动作文本等可实现替代，不假定画面已呈现。
当前选择必须依赖的事实，不能只藏在一闪而过的表情、颜色或小字道具中；通过可读文本或可访问说明提供等价信息。未到揭晓时点的秘密仍按主规则保留。
13.4.1 口语化（2026-10-31 产品方硬性要求）
所有给玩家看或听的文字——对白、旁白、动作、建议回复、短信、通话——一律用口语，像真人聊天那样说话：句子短、用词日常、可以有省略和语气词。不用书面语、不文绉绉、不堆成语和四字词、不写翻译腔、不写华丽的景物描写。旁白也用大白话交代“发生了什么”。运行时每次调用模型都会附带这条要求。
13.5 删冗语与语义保留
按顺序压缩：明确本句功能 → 保留事实、动作与人物态度 → 删除重复说明和空泛起手 → 用准确动词替代泛化动词加修饰 → 拆开多重从句 → 把可演出的细节交给画面 → 最后读成自然口语。
优先删除无作用的副词、形容词、套话、同义叠加、已知背景和对白后的解释。例如“他温柔而又关切地轻声问道”可只保留角色的问句与必要演出。
副词、形容词并非全部删除。否定、频率、时间、程度、条件和范围词如果改变事实或关系，必须保留。例如almost、still、only、again、not不能按词性机械删除。
拆长句时保留主语、指代、因果、条件、时间顺序及情态。“可能”不能改成“确定”，“想做”不能改成“已经做”，“如果你愿意”不能改成命令。
不设置全篇统一删字比例。短而含混、失真或失去角色声音的版本，应改写而非继续砍字；不能为减少字数让信息越级、遗漏代价或增强承诺。
13.6 语法、短句与人物声音
默认一句表达一个主要意思，优先常用具体词、自然语序与容易辨认的指代；减少多重嵌套、双重否定和一串抽象名词。主动语态优先，必要的被动和复杂时态仍可使用。
英语可从“多数普通句约5—14词，超过20词时检查能否拆分”起步；一个显示单元通常1—2句。均为项目初始编辑参数，不是语言标准、硬上限或对阅读能力的诊断。
用长短变化形成节奏，不把全文写成连续的三四词命令或缺失逻辑的碎片。情绪落点可以很短，解释必要因果时允许稍长；不能为了短句把一句自然回答拆成多次无意义点击。
明确人称、代词、时态、单复数和说话对象；几个人同时出现时，宁可适度重复名字，也不要为了少字使he／they／it所指不清。
角色之间保留句式差异：寡言者更少解释，严谨者说清条件，健谈者有更明显的节奏与幽默。相同信息可以有不同声线，不统一改写成客服话术。
句长、断句与文本框适配按目标语言重新处理；不将英语单词数直接套到中文、日语或其他语言，也不按中文原句一比一切割译文。
13.7 地区本地化与俚语
本地化前明确target_locale、时代与地点、角色年龄／背景、关系阶段、交流场景和正式程度；地区未定时使用中性易懂表达，不把“海外”自动等同美式英语。
翻译以含义、说话意图、人物声音和语用强度为单位，不逐字保留中文语序、成语、网络梗或称呼。译文不能擅自增加恋爱程度、粗口、性意味或攻击性。
俚语、口语缩略、双关、讽刺与昵称只在角色和语境需要时使用；自然口语不等于流行梗堆砌。无法确认适用地区、年代或含义时，优先给出清楚的自然表达。
核心规则、不可逆风险和结局条件不只用难解俚语或文化典故承载；必要时让含义通过自然回应或相邻文本落地，不强塞字典式解释破坏交流。
保留影响行动和关系的时点与程度差别，例如喜欢／爱、想要／承诺、可能／一定、今晚之前／今晚之后。目标语言的代词、称呼和敬语变化不得静默改变玩家身份或双方关系。
为角色维护目标语言声线卡：常用词、句长倾向、礼貌与幽默方式、口头禅、昵称条件、允许／避免的俚语及语气强度。术语、名字和称呼采用一致词表。
13.8 按需使用大模型辅助表达
可在出现生硬直译、地区口语、双关、讽刺、昵称、时代用语或人物声线偏差时，按需使用大模型辅助改写；不要求每一句再次调用模型，也不把大模型输出自动视为本地表达已被核实。
提供输入：原句、语义底稿、上下文、说话者与对象、人物声线卡、地区／年代、关系阶段、表达意图、不可改变的事实与语气、长度倾向及已支持演出；不只给孤立句子要求“更地道”。
输出优先给出自然直白版本；需要时附更口语或更贴人物的候选、含义差别及俚语说明。候选数量按任务需要，不额外修改剧情、条件、承诺或人物底线。
改写后进行语义与声线核对：事实、否定、条件、程度、时间、指代、关系阶段和知情范围不变；保留真实未决项，不通过润色自行补设定。这属于文本编辑，不展开测试样板或验收计划。
有真实工具／模型调用结果时才记录已调用；仅由当前生成器完成改写则如实记录。俚语真实性、地域与年代缺少依据时保留待核实标记，并提供不依赖该俚语的可用版本。
14｜普通道具与付费路径
道具与付费内容通过发现路径、行动能力、代价与独有经历影响体验；事实和人物自主条件保持一致。

选项改变意图与方法；普通道具改变线索、能力、发现时间或代价；付费内容可增加额外视角、独有经历或替代方案。不得凭空生成证据、改写事实或替玩家决定感情。
所有玩家均能经免费路径理解核心事件与真相，拥有重大选择的基本知情权，并获得至少一个完整有效结局；不得以付费纠正必要误会，或令不付费必然BE。具体额外场景可付费独有。
无道具可转支线、延迟发现、增加代价或失去特定机会；是否影响事件结局预先定义。免费替代不必复制付费体验，付费差异也不能只表现为加分或默认垄断所有最佳结果。
道具契约：item_id／offer_id、叙事功能、前提、持有与使用权限、人物合作意愿、即时效果、消耗、知识归属、角色解读、分支变化、免费替代、独有边界、延迟兑现及重复／无效使用处理。
节点分别写明持有使用、持有未用、未持有三种去向；购买与使用分开。仅在有效提交时消耗，不因生成重试重复扣除，不以付费越过角色自主条件。
15｜自由输入、知识与记忆
自由输入可以提出合法行动，不直接覆盖世界事实；记忆需要区分发生、感知、理解和后续调用。

自由输入区分表达、询问、猜测、请求、承诺、行动尝试与明确同意，映射到当前行动空间。合理替代方案可形成局部行动提案；“我已拿到证据”不直接成为事实，含糊的重大意图先澄清。
记忆生命周期：发生 → 被谁感知 → 如何理解 → 记录 → 后续调用 → 兑现、修正或结束。记录来源、知情者、事实／自述／推断性质及调用范围，重复内容合并并去重收益。
现实自述、玩家剧情身份与NPC世界事实分开存取；现实工作、家庭和情绪经历不自动变成剧情事件，映射需要用户意愿及世界允许。
后续调用受当前场景、人物知情权限、关系和用户记忆意愿约束。普通陪伴聊天不能跳过必要事件与行为证明刷出全部结局。
“别再提”停止主动调用；“不要记住”按平台能力停止写入／调用并处理删除请求，涉及既有记录时明确能力范围，不虚称已删除。私密事项不因偶然提及就默认永久保存。
16｜日常陪伴与稳定关系
主线推进与日常生活共同形成相处深度。关系确立后继续产出具体内容，不靠反复重置关系维持刺激。

配置六模块：陪伴节奏、现实与剧情边界、角色日常生活、共同活动、后续关心、稳定关系内容。每个角色有可辨认的相处方式，不统一使用客服式提问与安慰。
允许闲聊、安静相处、换话题和暂停主线；不将每次聊天强行导向任务、冲突或亲密升级。角色既回应玩家，也分享自己的持续生活、兴趣、小目标与见闻。
共同计划、读书、散步、玩笑等可参与、可跳过、可暂停或改变；回访承接上次内容，也允许今天聊别的。
后续关心记录事项状态、主动提及许可、合适时机、敏感程度、最近提及时间与结束条件；不反复追问已关闭、已解决或不愿提及的事项。
现实离线不自动扣关系、违约或触发坏结局，不用责备、失望或连续签到惩罚催回访。故事内已选择的期限与后果单独记录，不能混用现实时间。
主线结束、关系确立或好感满值后，继续积累共同生活、记忆、习惯、专属表达、不同意见及新情境反应；不靠无限抬高数值、周期误会或反复分手维持内容。
持续陪伴为长篇提供相处深度及阶段承接，可单列为主线后续增量；基础24小时以上容量不能只用“未来可以一直聊”作保证。进入预算的日常活动应有实际可用内容与记忆变化，仍允许玩家自由跳过和换话题。

17｜高潮路线、结局矩阵与后续
结局模式规定结束与开放的方式；四轴规定最终分别结算什么。两者同时使用。

guided：明确结局契约及多条达成路径；open：定义世界边界、当前关系及未解决目标，允许继续创作且不覆盖已发生事实；hybrid：结算核心事件，关系、人物变化及后续可开放。
四轴分别结算：事件结果、关系结果、人物弧光、持续状态（正式结束／开放续写／持续陪伴）。主线失败可有有效关系结果，恋爱成功不自动等于事件成功或弧光完成。
独立高潮路线至少改变高潮场景、核心问题、合作／对立人物、资源、关键行动、代价中的两项，至少一项涉及核心问题、人物关键行动、合作／对立关系或代价；只换背景、道具或结尾台词不算独立高潮。
可先设计3—5个事件／高潮结果族，短篇可更少，再叠加关系、弧光和后日谈片段。组合不必全部可达，互斥条件与原因写清，不生成无意义的全组合结局树。
结局资格 = 必要事实 + 关系阶段 + 关键行为证明 + 未修复冲突处理 + 玩家最终意愿 + 人物自主条件。数值辅助判定；无需的条件写无，不以好感总分替代事实与行为。
结局卡填写 ending_id、入口路线、必要条件、阻断条件、优先级、资格并存时的选择方式、条件不足去向、四轴结果及后续继承。不得临时选择作者偏好结果，不可无理由判BE。
失败必须可解释；是否可修复、可逆或可回溯预先定义，允许真实不可逆损失，但每条结束路径有明确合法去向。拒绝恋爱或选择朋友不自动变成事件失败。
结局读取主动发现、修正判断及真相后行动，不把听到解释直接视为成长；持续陪伴继承关系、共同记忆、弧光结果、未完成事项及边界。
17.1 四轴结算
结局轴	负责内容
事件结果	外部问题解决、失败、妥协、转化或明确开放
关系结果	疏离、理解、朋友、暧昧、恋爱、稳定关系或分开
人物弧光	推进、稳定、停滞、退化或转向
持续状态	正式结束、开放续写或稳定陪伴
结局资格由必要事实、关系阶段、行为证明、未修复冲突、玩家意愿和人物自主条件共同构成。无须参与的条件明确为无，多个资格并存时采用预先定义的选择与判定方式。

18｜状态裁决、存档与创作者版本
程序负责持久事实与结算，生成内容负责提出合法候选。创作者修改上游设定时，同步更新受影响的章节、路线、表达与容量。

18.1 运行状态与存档边界
程序控制持久状态、条件、节点分支、资源、权益及结算；AI提供表达、情绪、合理局部行动和候选状态效果。AI不直接提交未裁决事实；仅编写静态剧本时输出条件与效果，不虚称已执行。
条件满足并提交成功后，才将行动写为已发生；重复请求、重试和回溯不重复消耗资源、发放奖励或兑现种子。无效行动保留解释及合法去向，不默认为成功。
场景切换综合目标完成、自然收束、退出／替代方案和软轮数提醒；玩家可拒绝或退出，不按轮数强制推进、翻脸或结算。退出后记录暂停、转线或结束，不自动等同失败。
存档与知识权限按玩家、角色、故事、版本及存档路线隔离；不同玩家与不同存档不得共享未授权剧情记忆。明确现实时间、故事时间与可选期限的推进规则。
状态变化记录来源节点／选择、前后值或事件标记、知情者及后续读取点。回溯恢复对应剧情快照，避免未来知识泄漏；跨存档元知识须显式配置，不默认携带。
付费权益与剧情内道具分别管理：回溯可恢复剧情消耗状态，不自行撤销现实交易或重复发放权益；具体回溯策略由平台定义，生成器不得假设退款、重购或扣费已完成。
已提交事实、角色证词及玩家推断分开存储；程序能力、记忆删除、真实检索、模型调用或外部操作没有实际结果时，不宣称执行成功。
区分现实经过时间、故事推进时间和有效游玩估算；暂停、等待模型、加载与挂起不自动计入内容容量，也不自动推进用户未选择的期限。
对白、画面指令、旁白与内部语义／信息权重字段分离；屏幕只展示实际文本与已支持演出，不把本地化说明、模型过程、分钟预算或编辑分析混入玩家对白。
18.2 修改联动与版本管理
创作者可修改设定、节点、条件与结局，并记录 story_id、version、稳定节点ID及变更范围；废弃ID不复用于无关内容。
修改人物／世界规则时，联动数值、弧光、阶段、反转、分支、场景、记忆和结局资格；交付受影响范围的完整生效正文，同一规则只保留一个生效版本。
已有存档不能静默混用新版本：明确固定原版本、显式迁移或重开策略；迁移保存事实、知识、资源与权益一致性，不虚构过去发生了新版事件。
按请求层级交付：架构给体验、边界、人物核心、四轴方向、长篇容量、阶段／章节与玩法地图；人物给母档、行为规则、持续生活、声线及数值／弧光；章节给实际内容功能、场景／玩法与时长构成；分支给路线、选择、种子、汇合、道具、结局资格及路线容量；场景给进入条件、目标、节拍、行动空间、信息权重、知情限制、效果、记忆、退出及下一节点；正文给符合第13节要求的对白、画面、必要旁白和条件版本。
精简对白、改变目标语言、增加／删除玩法或调整路线后，同步更新受影响章节的实际文本量、演出需求与路线分钟估算；不能只改写作参数，保留已经失效的24小时结论。
在相应层级交付本文件内可独立使用的完整内容，不要求执行者另读一份对白附件才能知道核心表达要求。

20｜素材来源与原创边界
研究资料用于支持世界、人物与互动机制，原创转化必须与已取得资料分开；以下要求不改变各阶段的实际生成范围。

只引用实际取得的资料，source_type 仅用 verified／user／idea：verified 为已取得并可核对的外部资料，user 为用户提供资料，idea 为原创构想。三者不等同版权授权或最终事实确认。
来源记录标题、作者／机构、链接或文件定位、取得时间、支持内容及核实状态；无法访问或证据不足明确标记未核实，不补写不存在的引文、数据或结论。 未取得的外部候选资料记录在 pending_sources，不赋予 verified；只有用户提供了该资料时才能以 user 标注其来源，同时保留独立的未核实状态。
记录使用权限与版权状态；可访问不代表可商用。全程原创优先，不粘贴受版权保护作品的长篇正文，不把专有设定、标志性桥段与人物关系照搬为原创；授权不明不写成已授权。
趋势结论说明平台、时间范围及样本局限；区分资料事实、基于资料的判断及原创提案。少量案例不能直接代表“大部分市场”。
不用题材标签替代人物动机，不把虐待、占有或越界行为自动解释为爱；可按项目边界写复杂关系，行为、伤害与后果仍须成立。
不伪造真实执行、检索、验证、模型调用、状态提交或平台能力。资料不足时仍可提供明确标为 idea 的机制建议，不冒充已有来源。
如本次任务包含素材研究，可交付 source_cards / trends / originality_risks / motif_cards；保留来源定位、取得时间、核实状态、使用权限、适用范围、样本局限及原创转化。未取得的候选单列 pending_sources。未要求研究时，不为了填表伪造资料或检索过程。

生成结果按需要记录 story_id / setting_version / generation_scope / setting_status / assumptions / missing_inputs。结构版本与故事版本分开，confirmed／proposed／pending不代替来源分类。

21｜生成 Skill 总指令
依据当前已确认设定与指定层级生成互动剧本。单本全本目录控制在15—20章，普通完整路线以24小时以上有效游玩为容量目标，按实际可达、非重叠内容估算；章节、场景、玩法和长线相处共同支撑时长，不累加互斥路线、等待或无内容重复。先定义体验承诺、世界与玩家身份边界和完整人物，再确定结局方向、阶段／章节、互动循环、认知情绪链、分支状态及场景，最后生成对白和演出。开篇以具体行为呈现角色吸引力、态度与参与空间，世界按体验选择、当前行动和深入理解分层展开。采用纵向阶段主干与树状分叉，重要选择有实质后果与后文读取，汇合保留经历，长路线明确入口、转线窗口和锁点。事件、关系与弧光分别推进，四轴结算尊重玩家意愿和人物自主性。人物行为由画像、知情、压力、关系与弧光共同推导，数值不替代关键经历和行为证明。区分事实、观察、证词、可能推断与预期情绪，以可回溯线索和自主判断形成连续反转，并在揭晓后留出行动、回应和关系余波。信息按P0—P3安排交付，选择依据说清，表白、承诺和关键表达优先让角色直接对玩家说；画面补充具体差异，旁白只补必要说明。删除无效修饰、重复与赘词，拆分长句但保留否定、条件、时间、程度和人物声音；按目标地区本地化，必要时使用大模型辅助俚语，未调用不虚称调用，未核实不伪称地道。自由输入提出合法候选，事实、资源、权益与结局由程序裁决；道具改变路径与代价，不改写真相和人物底线。维护跨章知识、承诺、记忆、世界反馈及未修复冲突，持续陪伴有真实生活与稳定关系内容。按任务交付完整生效正文和相应模板，修改上游同步联动下游及容量估算，不保留互斥设定、补丁式增补或混用存档版本。
