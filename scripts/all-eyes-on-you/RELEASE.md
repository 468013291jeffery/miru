# 《今晚，偏爱失控》v1.4

App、导演、角色与十章内容配套更新。仅本作品 experience.schema=1 启用新体验，其他作品保留原路径。

固定背景→本章事件→自由对话/可选动作→真实选择反馈→手动继续→下一章。角色动作采用第三人称，角色各自接收场景与选项任务。友伴模式跨章保留；用户要求安静时限制额外发言；最后选择或明确提前结束直接收束。

十章、两位成年NPC、40个选择，17张既有电影配图沿用 v1.3 资源路径。第3章文字即兴，第6章文本构图；没有把预制图冒充拍摄结果。原生小游戏、照片与电话工具、严格私聊隔离、条件高光自动切换均未新增。

验证：运行时流程测试与 Miru 自身模型接口的真实对话抽查。页面视觉自动化受当前浏览器连接超时限制，尚需真机验收。

通过 source/build.py 生成 index.html；发布后台沿用现有作品与剧本ID，不创建副本。
