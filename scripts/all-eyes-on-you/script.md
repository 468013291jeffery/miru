# SCENE｜星幕影院·散场后的预留小厅
⟦BG|bg_c09s01⟧
⟦TIME|同夜·公开活动结束后⟧
旁白：公开活动结束后，星幕影院小厅里多了两张邀请卡。艾德里安想约一次没有安排表的早餐，诺亚想陪你看一场不用表演的旧片。谁都想被你留到下一次，谁也不打算替对手让步；时间仍等你来定。
旁白：预留的小厅安静下来。桌上有两张没写时间的卡，都还没有变成你的行程。
艾德里安：“我有一个下一次的提议。你愿意听吗？”
诺亚：“我也有。这次不打算替他让步，不过决定权还是你的。”
⟦FREE|听一份、听两份，或者把下一次改成你的版本。|艾德里安，你先说|诺亚，你打算怎么约我|你们不许互相退出⟧
# CHOICE｜听一份、听两份，或者把下一次改成你的版本。
#### A｜艾德里安，我想听你的下一次
艾德里安：“找个你愿意的早晨，一起吃早餐。没有发言稿，也没有整页安排。”
#### B｜诺亚，你下一次还要演吗
诺亚：“下一次想和你挑部旧片。没镜头，没采访，也不用谁负责有趣。”
#### C｜都可以争，但不许替我决定
诺亚：“那我把旧片夜留作一个提议，不先写进你的日历。”
艾德里安：“我也一样。不替他退，也不替你选。”
#### D｜今晚就很好，先别约以后
艾德里安：“好，卡先收起来。”
诺亚：“那我们把今晚好好过完，不预支下一次。”

# CHAPTER 10｜先把下一次，交给你
⟦GOAL|这晚被认真记住，选择属于你；没有被迫选出唯一正确答案。⟧
# SCENE｜星幕影院·出口旁
⟦BG|bg_c10s01⟧
⟦TIME|同夜·你愿意收束这一晚的时候⟧
旁白：同夜，星幕影院出口旁的灯还亮着。艾德里安与诺亚各留着自己的邀请，等你决定接下哪一份心意。你的一句愿意，可以让一个人不必再装从容；你也可以暂时不选，或把这晚留作朋友间的相遇。
旁白：窗上的雨迹慢慢变细。门仍开着，桌上的邀请也仍然没有替你填好答案。
艾德里安：“今晚到哪里，由你定。”
诺亚：“要把哪一段留到下次，也由你。”
⟦FREE|你愿意给谁下一次，或者希望怎样道别？|我想继续认识艾德里安|诺亚，下次别用台词|今晚先不选⟧
# CHOICE｜你愿意给谁下一次，或者希望怎样道别？
#### A｜艾德里安，我想有下一次
艾德里安：“好。下一次，我先听你想怎么开始。”
诺亚：“那这段时间留给你们。今晚能认识你，我很高兴。”
#### B｜诺亚，我想看你的下一场
诺亚：“那我记住了。下次不演，认真来见你。”
艾德里安：“好。祝你们有个合适的下一次。”
#### C｜都继续认识，暂时不定关系
艾德里安：“我愿意继续认识你。更深的关系，我们以后讲清楚。”
诺亚：“我也愿意继续。没有谁替今晚抢一个结论。”
#### D｜停在朋友，好好说晚安
诺亚：“晚安。谢谢你把今晚过成自己的样子。”
艾德里安：“晚安。路上平安，有需要再告诉我们。”
