# MIRU 我暗恋的人有秘密规则 18章逐场剧本 v1.0

**性质：** 双角色、18章、90个有内容的关键场景的中文主线剧本初稿。含作者端隐藏分支、GOAL/DONE、36处MG调用、画面和音效建议。不是已上线的运行配置，也不是24小时实测版。
**角色：** 玩家（第二人称，不自动代替其发言）；Rowan Vale（唯一有名且发言的角色）。其余只允许文件提示、无台词系统数据或不可辨认环境人群。
**呈现：** 无可见选项按钮；玩家在角色问话后自由输入。`OPT` 只作系统隐藏意图判断，三条加兜底，不把作者格式展示给玩家。
**同意：** 任何私密话题/行为都先征求玩家明确同意；拒绝/取消不影响主线；本文件仅谈边界，情节不含露骨性描写。

## 通用状态与接入约定

- `⟦SCENE|SCN_CHnn_01⟧`：场景分组；`⟦BG|...⟧`：与当章对应的视觉需求；`⟦MG|MG_CHnn_A⟧` 在第二场、`⟦MG|MG_CHnn_B⟧` 在第四场，必须是角色正在共同做的任务。
- `⟦GOAL|中文目标|English goal⟧` 及随后两条 `⟦DONE⟧` 是章节开头展示给玩家的内容。`DONE say` 由玩家表达判定；`DONE flag` 由剧情动作达成后提交。
- `OPT` 的 `player_intent` 是**隐藏分支匹配条件**，不可显示为按钮；`fallback` 兜底接到下一场，必要时 Rowan 用一句澄清问题。
- `SET` 标记是供运行时程序裁决的候选提交，实际状态应由产品端验证；游戏 win/lose/skip 均继续。
- 外部通知与邮件只能显示为可读文本，不出现第三名可互动角色，真实手机交谈只在两位不在同一场时使用；本稿场内主要当面说话。
