# 摄政王的床 The Regent's Bed

# CHAPTER 1｜行军床 The Campaign Bed

# SCENE｜三钟宫北塔地图室

⟦TIME|02:40 · 炉火将熄 · 室外 −4℃⟧
⟦BGM|bgm_maproom_night|frozen-ambience, dying-ember, single-cello⟧

旁白：地图室比王寝小一半。一张九十厘米宽的行军床支在地图柜之间，床头正对北境那张图——他十一年不肯睡进王寝，全宫都说这是清廉。

旁白：炭盆里最后一块炭塌下去，火星溅在铜网上。你站在床边，一步远。他侧躺着，被子只盖到腰，衬衫没换——白色的亚麻，后背被汗浸出一小片深色，贴在肩胛骨上。

旁白：你能看见那道伤。从右肩胛斜到腰侧，一道很旧的、被缝得很粗糙的疤。他睡着的时候，肩背的肌肉还是绷着的，像随时要从床上起来。

旁白：他的呼吸很匀。太匀了。睡着的人不会把呼吸排得这么整齐。

旁白：你伸手，停在半空。再落下去，指尖就会擦过他耳后——你告诉自己这是为了确认他有没有藏东西。这个理由连你自己都不信。

旁白：你的指尖刚碰到枕角，他的手动了一下——不快，甚至没睁眼——扣住了你的手腕。

旁白：他的手掌很热。虎口贴在你腕内侧，拇指正好压在脉搏上。他睁开眼，看着你，看了三秒。

Cassian：跳得很快。

旁白：他没有松手。拇指在你腕上按了一下，像在数，数完才慢慢放开。他坐起来，被子滑下去。衬衫敞着，露出胸口一片旧伤和冻出来的鸡皮。裤子前端完全支起。

旁白：两个人之间只剩半步。这张床太窄了，窄到你只要再往前一点，膝盖就会碰到他。

Cassian：你可以拿。

旁白：你抽出诏书，展开。他没有阻止，只是把身体往床里侧挪了半寸——那半寸让出了他能让的全部空间，也让你不得不坐上床沿。

旁白：床板在你身下响了一声。他的呼吸就在你肩后。他硬着，隔着布料顶着你的大腿。

Cassian：签，或者我来签。

你：废黜诏书，为什么在你枕下。

Cassian：因为三院明早要问，摄政王有没有准备。也因为我想在签之前先把你按在这张床上操一次。

旁白：他说这话的时候，没有看你，看的是你手里那张纸。火光从下面照上来，把他下颌那道刀痕照成一条很深的线。裤子前端的鼓起更明显了。

# CHOICE｜他的呼吸终于乱了一拍。你——

#### A｜"这份东西，写了多久。"

Cassian：十一年。改过七稿。
旁白：他说完，抬手替你把垂下来的头发别到耳后。这个动作他做得太自然了，自然到两个人都愣了一下。他的另一只手已经按在自己裤裆上。

#### B｜"你枕着它睡了多久。"

Cassian：沉默。炭盆又塌了一块。 ……两年。
旁白：他低头看你，忽然伸手，把你握着诏书的手指一根一根掰开，把纸卷拿走，放到床头的柜上——然后他的手没有收回去，落在你膝上，隔着裙子，很轻。然后他引导你的手按在他已经完全硬起来的地方。

#### C｜把比例尺横在诏书上，量墨的宽度："我要先验墨。"

Cassian：他笑了一下，很短，气息扫过你的耳侧。 半夜潜进摄政王的房间，先验墨。
旁白：他伸手替你按住比例尺的另一端，两个人的手在同一根铜条上，隔着一指的距离。他的指节比铜条凉。裤子前端顶着你的大腿。

旁白：你从第一款读起。读到第七款时，你的手指停住了。

旁白：他的头靠得很近，近到你能听见他呼吸里那一点杂音——右耳坏了以后，他自己听不见自己的呼吸有多重。他一直硬着，顶着你。

Cassian：念出来。

你："王冠若成为死因，移走王冠。"

旁白：房间里安静得能听见蜡油滴在铜盘上。

旁白：他伸手，把诏书从你手里抽走，卷起来，放回枕下。动作很慢，慢得像在给自己时间。

Cassian：陛下。他第一次用这个称呼，声音低得像在道歉。 你现在该回王寝了。或者你留下来，让我先把你操一次，再谈废黜。

# SCENE｜耳语廊

⟦TIME|03:10 · 墙内通道 · 宽四十厘米⟧
⟦BGM|bgm_whisper_gallery|stone-reverb, breath-echo, distant-bell⟧

旁白：回王寝要穿过北塔的耳语廊——墙里的一条通道，四十厘米宽，两个人错身都难。这条廊子的穹顶是弧形的，站在这一头说话，那一头能听见，连呼吸都能听见。

旁白：他提灯走在前面，走到一半停住，因为前面有落石。他侧过身，让你先过。

旁白：通道只有四十厘米。你贴着他的胸口挤过去，鼻尖几乎擦到他的衣领。灯在他手里，光照不到你们之间这块地方，只有两个人身上的热。他硬着，隔着布料顶着你的小腹。

旁白：他的心跳撞在你锁骨上。你自己的心跳更响。

Cassian：低声。 别说话。

你：为什么。

Cassian：这条廊子会传声。他停了一下。 你在我房间说什么，我在这条廊子里都听得见。十一年了。我想听你被我操的时候叫出来。

旁白：你抬头。他的下颌就在你眼睛上方，那道刀痕的末端隐在黑暗里。他的呼吸乱了，但身体一动没动——他在等，等一个不是他自己给的许可。他的鸡巴硬得发痛，顶着你。

# CHOICE｜通道只有四十厘米，他没有让开。你——

#### A｜伸手按住他胸口："那你听见我刚才在想什么吗。"

Cassian：他的心跳在你掌下猛地重了一下。 听不见。他低声说。 但我在猜。我想你在想我怎么把你按在石壁上操。
旁白：他终于低头。嘴唇擦过你的额角，停在那里，很轻，像在验一份他不敢签的文件。然后他抓住你的手，按在自己硬起来的地方。

#### B｜"让开。我要回王寝。"

旁白：他立刻侧身，把灯举高，让出通道。你走过去的时候，他没有看你。等走出三步，他才在背后低声说了一句。
Cassian：明天早上，我会在议事厅。你可以继续把我当一堵墙。也可以让我把你按在墙上操。

#### C｜"你在这条廊子里，听过什么。"

Cassian：沉默了很久。 你的呼吸。他把灯往下压了一点，光只照到两个人的鞋。 三年。每一夜。我想听你被我操的时候的呼吸。

# SCENE｜王寝门口

⟦TIME|03:35 · 王寝门前 · 走廊无火⟧
⟦BGM|bgm_threshold|low-drone, single-note-piano, held-breath⟧

旁白：王寝门前，他停下。门是开着的，里面黑着。他站在门槛外，一只脚都没有进去。

旁白：这是第一条定律：摄政不入王榻。全宫都知道，连扫地的侍从都知道。此刻这条法律在他脚下变成了一条看得见的线。

旁白：灯在他手里，火苗被走廊的风吹得偏向一边。他看着那扇门，看了很久，喉结动了一下。裤子前端仍然鼓着。

Cassian：很轻。 我十一年没进去过。

你：为什么。

Cassian：因为我怕躺上去，就不想下来了。也怕一旦进去，我会把你按在床上操到天亮。

旁白：他说完就退了半步，把灯递给你。递灯的时候，他的指尖在你手背上停了一瞬——那一瞬比他说的任何一句话都长。

Cassian：睡吧，陛下。他转身。 明天辰时，议事厅。带上你的比例尺。或者今晚就跨过来，让我先把你操一次。
