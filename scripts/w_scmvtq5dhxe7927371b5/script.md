# 第三个新娘 The Third Bride

# CHAPTER 1｜第四位 The Fourth

# SCENE｜岛南小码头

⟦TIME|16:20 · 九月 · 海面反光刺眼 29℃⟧
⟦BGM|bgm_island_arrival|mediterranean-warm, cicada, low-tension-undertone⟧

旁白：Isola Sirena，距西西里十一海里。接驳艇撞在旧轮胎上，咚的一声，你的膝盖先于你的脑子顶住了船沿。

旁白：码头边缘站着一个人。白衬衫，袖子卷到肘上，没系领带，领口开着两颗。阳光从海面弹上来，把他整个人照得发白——除了左耳后那一片疤，颜色浅得像被光洗过。他下坡走过来。不着急，每一步都踩得很实。你注意到他的手：很大，指节宽，右手三根手指微微向内屈着。还有一件事你注意到了：他走近的时候，空气里的味道变了。海水、机油，还有一点碘伏。

旁白：管家在他身后躬身。海鸟在头顶叫得像吵架。

Ansel：罗西夫人。

你：……你叫我什么。

旁白：他没有回答。他先伸出手，掌心向下，停在半空——不催，也不收。这个姿势太耐心了，耐心得像他已经练过很多次，等一个人自己决定要不要把手放进去。

# CHOICE｜他的掌心向下，很稳。你——

#### A｜握住他的手，借力上码头

旁白：他的掌心干燥，比海水凉。握住的一瞬间，他的手指收紧了一下——很轻，像在确认重量。三秒。他收手，退开半步，做了一个“请”的手势。但他的目光在你脚踝上停了一下，又慢慢上移到你的腿。
Ansel：小心台阶。他说这话的时候看的不是台阶，是你的脚踝和裙摆下的皮肤。

#### B｜自己跳上去："我不习惯被人扶。"

Ansel：他收回手，嘴角动了一下，不算笑。 在这座岛上，你很快会习惯被人扶。也会习惯被我看着。

#### C｜"先回答我。你认得我？"

Ansel：他沉默了两秒，那两秒里他把你从头看到脚，又回到眼睛。 我认得你写的东西。三篇。最后一篇你写“有些船是故意沉的”。他侧身让开。 那篇之后，我等你上来，等了十一个月。等的时候我已经想过，如果有机会，我会怎么把你按在没有摄像头的地方。

# SCENE｜Casa Bianca 试衣间

⟦TIME|17:40 · 白墙上的光斜成 45° · 屋里比外面凉十度⟧
⟦BGM|bgm_fitting_room|linen-rustle, distant-sea, quiet-pulse⟧

旁白：Casa Bianca 的白墙在坡上发亮。他领你上二楼，推开一扇门——一间试衣间，中央立着一个人台，上面挂着一件婚纱。

旁白：改好了。腰线收得很准，裙摆的珠片在斜光里像一小片碎海。你伸手翻内衬，指尖摸到缝在里面的两个缩写：N. 和 I.

旁白：你的后背有一瞬间是凉的。这件衣服不是为你做的。它只是被改成了你的尺寸。

旁白：他站在门口，没有进来。

Ansel：裁缝上周走了。裙摆还差两寸。他把一卷软尺放在桌上，没有递给你。 我可以叫船送你回岸上，等新的裁缝。

你：然后呢？婚礼推迟？

Ansel：他看了你一会儿。 或者我量。你决定。

旁白：房间很安静。你能听见楼下冰箱的压缩机。你忽然意识到一件事：这间屋子没有摄像头。整座岛 46 个，这间没有。

你：你为什么把这间留出来。

Ansel：因为试衣服的时候，不该有人看着。也因为我想在没有镜头的地方碰你。

旁白：他走进来，把门带上——没有关严，留了一指宽的缝。他跪下来，在你脚边，把软尺绕过你的脚踝。他的头顶在你膝前，你低头就能看见他后颈那截被太阳晒出的线。

旁白：他的手指碰到你的踝骨，很凉。你能感觉到那三根不太灵活的手指在绕过软尺时有一点点笨。他绕到膝弯的时候，呼吸明显乱了。软尺继续往上，经过大腿内侧时，他故意放慢，指腹隔着丝袜摩挲了一下。

Ansel：两寸半。他抬头。 你站得比我以为的稳。我已经硬了。

旁白：你伸手，指尖落在他左耳后那片疤上。皮肤是光滑的，没有毛孔，比周围凉一点。他整个人僵住了——不是躲，是整个身体在三秒内一寸一寸地停住，像被人按了暂停。三秒。他没有呼吸。第四秒，他呼出一口气，气息打在你膝上，热的。

Ansel：声音低了一层。 你为什么不怕。我可以继续量吗。往上。

# CHOICE｜他的手还停在你的脚踝上，没有收。你——

#### A｜"因为我在看的是你，不是那块疤。"

旁白：他闭了一下眼睛。然后他把额头轻轻抵在你膝上，只停了两秒，就退开——退开的时候，他的手从你脚踝滑到小腿，再滑到大腿内侧，隔着裙摆，很慢。他抬头看着你，另一只手已经解开了自己的皮带扣。
Ansel：别在这里说这种话。他低声说，像在跟自己说。 这间屋子没有镜头，但门没锁。如果你现在说可以，我会把它扯下来，用舌头把你舔到站不稳，然后操你。

#### B｜把他的手按回你的小腿上："继续量。你量到哪儿，我都不躲。"

旁白：他的拇指在你小腿外侧停住，压了一下，又松开。他低头继续绕软尺，绕到膝弯的时候，他的呼吸明显乱了。软尺滑到大腿根部，他停住，指尖隔着布料按在你已经湿了的地方。
Ansel：你知不知道你在做什么。你已经湿了。我可以进去吗。先用手指。
你：我在让你量尺寸。
Ansel：他抬眼，眼睛里那点克制已经薄得像纸。 不。你在让我记住这个房间。也在让我硬到发痛。

#### C｜收回手："先量完。剩下的，等我知道你是谁。"

旁白：他站起来，退开一步，把软尺收好，动作慢得像在给自己时间。他把那块疤重新藏回侧脸的阴影里。但裤子前端已经明显支起。
Ansel：合理。他把软尺放回桌上，指尖在桌沿停了一下。 但我建议你别在这座岛上说“等我知道你是谁”——这里每个人都在等别人先说实话。包括我想操你这件事。

# SCENE｜书房

⟦TIME|18:30 · 落日压在窗框上 · 室内 24℃⟧
⟦BGM|bgm_study_dusk|piano-single-note, clock-tick, sea-far⟧

旁白：书房在走廊尽头。三面墙是海图，第四面墙是一个玻璃柜，柜子里摆着 41 条船的模型。

旁白：他从腕上摘下一只男式手表，放在桌上。三点四十。秒针停在离十二四格的地方。

⟦ITEM|停在 03:40 的手表|火警响起的那一刻。表带内侧有一圈磨白的痕。|⌚⟧

Ansel：前任们的遗物。你迟早会翻，我先给你。

旁白：你抬头。他站在逆光里，左耳后那片疤在光边上，颜色浅得几乎透明。他左手还按在桌沿，那只手的三根手指微微屈着。裤子前端仍然鼓着。

你：这栋房子里有多少个摄像头？

Ansel：四十六个。他没有停顿。 四十五个在工作。第十二个是坏的，坏了四年。他停了一下。 你今晚睡的那间，是第十二个照不到的地方。如果你想，我可以今晚就过去。把你按在那张没有镜头的床上，操你，直到你忘记自己是来找尸体的。
