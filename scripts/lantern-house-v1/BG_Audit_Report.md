# 《Three Men, One Last Light》逐场BG落实核查报告（v1.4）

- 来源：《MIRU 互动剧本写作规范 v3.3》第五节（每场一张带人物背景、紧跟SCENE、竖屏9:16、941×1672 JPG约230KB、不可见文字、第一视角，玩家独处可例外）；现行《剧本_中文版.md》与《作品资料_中文版_v1.3.md》。
- 规范数量：每场1张BG，16章×每章3场=**48张不同场景需求**。
- 剧本文本检查：16章、48场、48个唯一BG ID；每个BG紧跟SCENE、后接TIME；编号与章场位置一致；48条都有在场人物及动作提示；缺失BG 0、重复ID 0、错位 0。
- 此前不足：上一版作品资料只概述了48张、未把48场的画面逐条汇总在中文审阅资料中；已有英文JSON，不够直观；没有清楚标出每张尚未出图的制作状态。
- 此次补充：在作品资料第11节新增48张逐场制作表；另交CSV/JSON，每场明确独立文件名、角色动作、地点时间、第一视角构图、9:16尺寸和制作/接入状态。正确的可执行剧本BG标签未改动，避免破坏解析器对应。
- **实际图片核查**：未发现本剧48张正式BG JPG素材文件，不能声称图片已制作/已上传/真机显示正常。请制作组按清单制作并回填状态，然后逐张检查人物一致性、图中文字、格式/尺寸/体积及真实资源ID是否与剧本相符。
- **CG区分**：作品资料提出8个CG高光候选，但当前可执行剧本里没有CG标签，不能将CG计入已完成图片，更不能算入48张BG。
