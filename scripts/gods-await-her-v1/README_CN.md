# 诸神都在等她点头：完整美术素材

依据：16章 × 每章3场 = 48场，最新版 Full_Script_CN_v1_1。

- backgrounds/：48张带人物剧情背景，JPG，941×1672；文件名与正文BG ID逐一相同。
- characters/：8张独立人物图，含玩家、三神、米拉、奥瑞克斯、伊芙琳、成年证人。
- Scene_Map.csv：章节、场次、人物、神态与动作及文件对应表。
- scene_manifest.json：逐场描述、剧情上下文、生成提示词、尺寸及校验值。
- PDF图册：2页人物图 + 16页逐章对照，合计18页。

每场采用分支选择前共同事件；邀舞、告白等画面停在等待玩家回应，不预设接受。玩家主角图单独呈现正脸，背景中不展示玩家正脸。伊芙琳为已故人物，独立定妆图用于回忆和档案，不表示她在场复活。

延续已确认的4张开场背景，补齐其余44场；三神和玩家另提供统一脸型的全身定妆图。场景中的微光/纸张只作叙事视觉，界面文字由程序叠加。
