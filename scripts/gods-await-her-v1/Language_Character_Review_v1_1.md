# 《诸神都在等她点头》行文与人物偏爱复核 v1.1

## 修改重点

1. **降低理解门槛**：将男主和米拉的大量“核验、程序、签章、条文、证据链”等书面口吻，改成短句和具体动作。法庭及世界规则保留必要词语，避免删除关键因果。
2. **提升玩家被珍视的体验**：男主在早期即主动照顾玩家，不能等到第13–15章才开始表白。情绪价值有具体行为兑现，而不是重复一句“我会保护你”。
3. **保持三人鲜明反差**：凯兰用安静、星灯与担当表达爱；卢森用幽默、公开偏爱与小惊喜表达爱；赛勒斯用倾听、细节和不催促表达爱。三位男主可真诚喜欢玩家，但不能预设玩家一定回应。
4. **人物卡同步**：每位男主新增“B14 对玩家的独有偏爱与陪伴”，标明早期情绪互动、后期兑现、应避免的同质化写法和适合的口语示例。
5. **续聊保真**：新增角色智能体的日常话题要求；故事结束后继续提供不催促、不索取回应的陪伴。

## 典型行文修改

| 旧写法 | 本版更自然的表达 | 改动原因 |
|---|---|---|
| “请允许我修正：钟鸣发生在十九点十分。” | “我记下了。钟声在七点十分响起，你是第一个听见的人。” | 赛勒斯仍精准，但不再像播报机器 |
| “缺页不影响紧急保护职责。” | “少一页也不能耽误救城。” | 反派仍有秩序逻辑，台词易懂 |
| “这是可以独立核验的实物位置。” | “你看出来了。这个编号是真实存在的，我们能找到那只柜子。” | 把抽象术语换成具体下一步，并肯定玩家 |
| “我喜欢热闹，也很喜欢你不必热闹的样子。” | “我喜欢你认真工作的样子，也想看看你放松的时候是什么样。” | 卢森表达具体的欣赏，不替玩家定义性格 |
| “我不想再用记忆替整个制度补错。” | “我不想再拿记忆去填这个无底洞。以后，我还想记住与你相处的每一天。” | 赛勒斯保留剧情冲突，补足个人情感 |

## 不可破坏的边界及剩余工作

- 女主的喜好、情绪、爱意和身体接触不能在旁白中被强制决定；偏爱可以是男主的主动情感，不等于玩家必须接受。
- 重大剧情选择（4、8、12章）仍影响后续内容，主线无需恋爱也能完成。
- 本轮调整的是中文审阅与制作稿；正式美国上线仍需逐句进行自然美式英语本地化。
- 48张BG是已确定的制作规格与清单，**不是已生成的图片**；小游戏方案尚需对应真实资源库 ID，平台语法需在部署前联调。
