# 午夜邀约 · 剧本与原始图片

本目录保存用户指定的《午夜邀约_完整剧本_含图片标注.txt》和《午夜邀约_全部照片.zip》中的全部图片。

- source.txt：完整原稿，逐字节保留，含 8 幕剧情、人物设定、执行规则和图片切换标注。
- art.json：按封面、人物、场景分组的静态图片地址；poster 与 cover 复用同一图片。
- slots.json：供后续接入核对的扁平素材对应表。
- meta.json：内容资料与当前接入状态。
- manifest.json：原稿和全部原图的 SHA-256 校验清单。
- 图片位于 art/official/midnight-invitation/，保持原文件名和 PNG 字节，不裁切、不重绘。

## 接入状态

当前完成内容文件上传，未发布为 App 发现页作品。原稿使用“第一幕”等创作稿结构，含角色私密规则、状态合同和后台说明；不能直接整份交给现有 MIRU CHAPTER DSL 解析器，否则可能把后台规则当旁白。

后续正式发布需保留本原稿，另行生成可玩剧本，确认后台分配的作品 ID、人物和场景标识，再绑定素材。本目录的 contentId 不是后台已经分配的 work_id；slots.json 中的标识为上传清单，不表示已经绑定到运行时。

本次仅新增本作品原稿、原始图片及内容清单，不包含本地应用源码、智能体测试程序、密钥或用户存档；不修改现有作品和应用逻辑。
