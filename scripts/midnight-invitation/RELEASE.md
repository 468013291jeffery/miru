# 《午夜邀约》Miru 导入包

主模式为现有 Bible98：用户扮演自己，八幕、多人物角色卡、自由对话与手动继续剧情。配套 script.md 为标准剧本导入文件，authoring-contract.json 完整保留原稿执行规则。source.txt 与二十张原始 PNG 不作修改。

发布工具使用 Miru 原来的 /api/admin 接口和现有后台账号；不连接新的数据库，不修改前端或 API 源码，不上传本地试验工程。先创建草稿、自动检查，再绑定该作品 ID 的故事圣经和素材表，确认素材部署完成后才调用发布。

当前引擎的限制：状态变化由模型记述，未实现逐事件事务；未实现严格私聊隔离与提前结束卡。图片只在场景入口切换。涉及互斥地点的幕使用中性色背景，不展示尚未到达或撤回的图片；全部原图仍保留在素材表。不能将此版本称为原稿全部执行合同已由程序实现。

发布状态须以 publish-result.json 和线上 /api/works 返回 live 为准，文件上传、自动检查通过和草稿保存都不等于已上线。
