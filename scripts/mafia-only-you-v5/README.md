# 全城怕他，他却怕我哭｜16章48场 CG 完整素材包

以四人版v5完整剧本为准：16章，每章3场，共48张独立场景CG。每张图含剧情人物、场景动作及对应的表情与神态。

## 文件内容

- scenes/：48张独立竖屏剧情CG，按bg_c01s01至bg_c16s03编号。
- characters/：4张人物定妆参考图（带背景，非透明立绘）。
- music/：4首原创合成配乐，含MP3和WAV。悬疑53.33秒、温柔53.33秒、危险40秒、反击40秒。
- effects/：6种SVG/CSS互动动画和独立可点击预览（不是特效视频）。
- Full_Script.md：原始完整剧本。Story_Character_Guide.md：故事及人物设定。
- scene_manifest.json：逐场图像、配乐、特效和推荐触发事件映射。
- index.html：离线图像总览、音乐试听和特效预览。
- prompts/：本轮新生成/重做场景的提示词记录。

## 使用方式

解压后用浏览器打开index.html，点击缩略图查看原图。音乐需要点击播放，不自动播放。点击高光/选择/消息按钮查看叠加动画。
根据scene_manifest.json的scene_id与原剧本BG标签逐场绑定，工程端仍需接入资源与事件；本包没有修改MIRU工程。
推荐对白期间音乐降低12–18dB，换曲时0.3–0.8秒交叉淡化。音乐按整小节生成，循环时建议引擎做短交叉淡化。
场景为单帧CG，不是动画视频。构图已强调人物动作、表情和神态；准确证据文字、时间与交互按钮应由产品界面渲染。
个别屏幕中的文字属于图像示意，正式上线前应按UI方案覆盖或校对。原始图片分辨率保留，未做放大。
