角色文件沿用characters/char_角色键/char_角色键__状态.png；底图沿用bg_cXXsXX.jpg。manifest.csv为统一槽位清单，含路径、场景时间、规格及SHA-256。validation.json记录导出检查；generation_prompts.json保留图像生成与修订记录。

风格沿用已确认的电影写实、灰黑米与黄铜主色。普通底图去除人物动作，人物互动由立绘和高光承担。少数高光采用此前确认的浪漫动作改编：试香纸、完整晚礼服舞会、腕部表面电极、并肩钢琴示范、带安全绳的平衡训练、递花与自行整理头发等。Rafe的shirt状态为白衬衫外加敞开马甲。prop_01是一张评分卡正面，不代表十九张卡所有状态。

本次“完整”指已制作的全部图片素材合包；不包含BGM、音效、预告视频及独立特效。各图片直接合并，未再次有损压缩；旧阶段版、待修订图与参考拼版未混入正式目录。
