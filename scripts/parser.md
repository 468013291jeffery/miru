# 剧本解析规范（给前端实现）

> 2026-10-31。这份说的是**一段剧本文本怎么变成可播放的事件流**。
> 写法规则在同目录 `syntax.md`（编剧看那份），这份是实现契约（前端看这份）。
> 每一条都对着 MIRU 现行解析器核过（`source/src/app51_import.js` / `app94_official2.js`）。

---

## 一、输入到输出，一共四步

```
script.md 文本
  ①  行扫描 → doc{ chapters[], title, cast, pov, scenes, choices, lines }
  ②  章节内 items 拆事件 → beats[]
  ③  指令展开（⟦K|…⟧ → 事件，或挂到上一个场景上）
  ④  事件流 → 播放器逐条消费
```

`scriptVer = 2`。**这一份描述的就是 v2** —— 与最早给你们的版本相比有三处变化，见第四节。

## 二、行级识别（第 ① 步，按顺序匹配，先命中先定）

| 行的形状 | 判成什么 |
|---|---|
| `# CHAPTER n｜标题` / `# 第n章 标题` | **章**（新章开始，之前的收尾） |
| `# SCENE｜地点` / `# 场景｜地点` / `# 第三场｜地点` | **场景**（`doc.scenes++`，产出 `sys scene`） |
| `# CHOICE｜问题` / `# 选择｜问题` | **选择点**（其后的 `#### A｜…` 是选项） |
| `#### A｜选项文字` / `A. 选项` | **选项**（A–E） |
| `#### 入口A｜说明` | **分支入口**（上一章选了 A 才播） |
| `【心理】` / `【内心】` / `【心声】` / `【OS】` / `【独白】` | **心声**；下一行若是引号句，整句是心声 |
| `名字：台词`（名字 1–16 字，可带 `（语气）`） | **对白**，`who=名字` |
| `旁白：…` | **旁白** |
| 其它非空行 | **旁白**（动作/描写，一段一个气泡） |

⚠️ **三个必须照抄的细节**（都会静默出错）：

1. **无 `#` 的自动升级只认英文**：`SCENE｜…` 可以不带 `#`；`场景｜…` **必须带 `#`**，否则整行当旁白（还会把它**显示给玩家**）。
2. **中文场景名必须带 `#`** —— 同一件事，写成 `# 场景｜酒店走廊`。
3. 空行是段落分隔，不是事件。
4. **第一个 `# CHAPTER` 之前的所有 `⟦…⟧` 行，全部属于第一章**（`⟦CHAR⟧` 角色卡、`⟦ORIENT⟧`、`⟦SECRET⟧`、`⟦GOAL⟧`…）。它们跟正文之间常夹着 `## 1.1 故事简介` 这类小节标题，**标题后面还有指令** —— 所以不能「从第一个 `# CHAPTER` 开始切、前面全当前言扔掉」。实测（2026-10-31，一份真稿子）：只往前捞 `⟦CHAR⟧` 的实现，把 1 条取向和 6 条秘密当「后台设计」丢了；而回执只写「丢掉 24754 字符」，从回执上完全看不出来。

## 三、指令 `⟦K|a|b⟧`（第 ③ 步）

`K` 必须在白名单里，否则**整条按原文显示给玩家**（这是最坏的失败模式，务必在你们那边也拦）。

| 指令 | 参数 | 变成什么 |
|---|---|---|
| `CHAR` | 名字\|性别\|年龄\|立绘\|身份\|描述 | 角色卡（`doc.cast`，性别 m/f） |
| `ORIENT` | `bg`/`bl`/`gl` | 取向 |
| `BG` | 槽位\|地点 | **不产事件**，挂到上一个 `sys scene` 的 `bg` 上 |
| `TIME` | 时间 | 同上，挂 `time` |
| `BGM` | 标签\|风格 | `sys bgm` 事件 |
| `CG` / `VIDEO` | 槽位\|说明 | `sys cg94` / `sys vid94`（**独立的图像/视频事件**） |
| `PHOTO` | 标题\|说明 | `sys photo94` |
| `MG` | 小游戏 id | `sys mg` |
| `ITEM` | 名字\|描述\|图标 | 道具卡（暂停约 0.9 秒后继续） |
| `SET` | 旗子名 | `sys set`（打旗） |
| `IF` / `ELSE` / `/IF` | 条件 | 条件块（`sys if` + then/else 两组事件） |
| `OPT` | 选项\|效果 | 选项效果（`set:` / 好感增量） |
| `GOAL` | 中文\|英文 | 章节目标 |
| `SECRET` / `REVEAL` | … | 认知边界（v2 新增） |
| `FREE` | 问题\|选项1\|选项2… | **中段选择点**（= 一个 choice，允许玩家自由输入） |
| `CALL` / `/CALL` | 角色\|情境 … | **通话卡**（`[@角色, "call"]`，**唯一会让播放停下等玩家**的指令） |

**`BG` / `TIME` 找不到上一个 `sys scene` 时，静默丢弃**（不报错）—— 所以每个 `⟦BG⟧` 前面必须有一个 `# SCENE`。

## 四、v2 相比最早那版，变的是这三处

| # | 变化 | 影响 |
|---|---|---|
| 1 | **中文场景名被正式支持**（`场景｜` / `第N场｜` / `第N幕｜`） | 但**必须带 `#`**；不带就漏成旁白 |
| 2 | **新增 `⟦ORIENT⟧`** —— 取向不再只能从 `⟦CHAR⟧` 性别推断 | 建议每个作品第一章写一行 |
| 3 | **新增 `⟦SECRET⟧` / `⟦REVEAL⟧`** —— 角色的认知边界（谁在什么时候知道什么） | 不写就是全知，会剧透 |

另外两条口径没变、但常被问：
- `# CHOICE` 那个块**必须以 `# ·` 收尾**（一行 `# ·`）。少了 ⇒ 后面的正文被算进最后一个选项。
- 一章里**最后一个 `# CHOICE`** 是章末选择；之前的都是章内选择。

## 五、事件流形状（第 ④ 步）

```
["sys", "scene",   {place, time, bg, img}]     换景（同时更新状态栏）
["sys", "bgm",     {m}]                         音乐
["sys", "cg94",    {slot, cap, src}]            插画
["sys", "vid94",   {slot, cap, src}]            视频
["sys", "photo94", {t, cap}]                    照片卡
["<cid>", "say",   "台词"]                       对白
["n",     "act",   "旁白"]                       旁白/动作
["<cid>", "think", "心声"]                       心声
["sys", "set",     {flags}]                     打旗
["sys", "if",      {cond, then, else}]          条件
```

- `<cid>` 是角色 id（由 `⟦CHAR⟧` 卡与出场统计生成）
- **播放会停下的只有两种**：`choice`（等玩家选）与 `call`（通话卡）。其余事件按阅读时间自动推进
- 阅读时间：中日韩字 ≈ 105 ms/字，封顶 7 秒

## 六、`mode=bible` 的解析（不解析文本）

`bible.json` 里场景是**结构化数据**，不做行扫描：

```json
chapters[] = { n, title, goal, card98{}, scenes[] }
scenes[]   = { id, place{zh,en}, beat, present[], script[], opts[] }
```

- `beat` = 一句场景锚点（导演照它演）
- `script` 可选：`[{who, k:"say"|"act", zh, en}]`，有就逐字演
- `opts` 可选：`[{k, t}]`，有就出选项
- **取图规则**：场景图 `bg_<scene.id>`、立绘 `char_<cast.key>`、封面 `cover`。名字对不上 ⇒ 静默不显示

## 七、你们那边至少要拦住的五类错

1. 未知指令 `⟦XXX⟧` —— 不要原样显示给玩家
2. `# CHOICE` 块缺 `# ·`
3. 中文场景行缺 `#`
4. `⟦BG⟧` 前面没有 `# SCENE`
5. **前置指令被当「后台设计」丢掉** —— 判据：解析出的角色卡 / 取向 / 秘密的**条数**，必须等于原文里对应 `⟦` 行的条数。

前三条在 `syntax.md` 的第四节也写了（给编剧）；第四、五类只有解析方看得见。
