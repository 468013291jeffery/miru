# MIRU Three Pilot Stories Revised Edition

版本：2026-11-20 第二版

## 为什么重写

第一版的主要问题是过早堆叠人物、公司/族群术语和系统控制标签，没有让玩家先弄懂自己为什么来到现场、眼前要解决什么。

本次重写保留三个故事的核心题材，但每个开场统一做到：

1. 前三段交代玩家处境与来这里的理由。
2. 第一场出现明确问题和不同性格的人物反应。
3. 每章都让玩家知道当下目标、获得一个确定答案、遇到下一个悬念。
4. 玩家以自然语言回复，不强制选择按钮；剧本中少量“你”台词只是演出示例，产品播放时由玩家输入覆盖。

- 02_Too_Late_To_Want_Me_Back_Rewrite_CN.docx：离婚三个月后的事业与感情选择。
- 03_I_Rejected_The_Alpha_Rewrite_CN.docx：暴雪山谷、狼王与月印之谜。
- 04_Revised_10s_Trailers_And_Character_Briefs_CN.docx：三个单场景十秒英文预告及人物视觉设定。
- 05_Revised_36_Scene_Art_Briefs_CN.docx：前四章合计 36 张 CG 的新版本制作要求。

上述 5 份 Word 同时附有 5 个 Markdown 可编辑原稿。

## 完成范围

每部具备完整 16 章连续因果大纲、前四章各 3 场可直接供创作者审稿的正文、每章两个小游戏玩法摘要、明确的角色动机和章末悬念。

这不是 16 章全量 24 小时正文。后 12 章需要进一步逐场扩写；角色参考图、场景 PNG、预告 MP4 尚未生成，也没有接入 MIRU 智能体接口。正文中为保持可读性，暂不混入原版本冗长的程序化分支标签；真正上线前需将自由回复规则映射到项目接口。

## 三条必须保留的剧情原则

- 派对篇：朋友 Mia 失联是玩家行动的起因；每条线索都有来源，不能用凭空出现的神秘消息解决故事。
- 离婚篇：离婚已发生三个月，玩家去公司是为保护原创作品；Adrian 的道歉不等于权利自动回到玩家手里。
- 狼人篇：暴雪解释玩家为何进庄园，月印不是婚姻同意；法阵的损坏早于玩家到来。
