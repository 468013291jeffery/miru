# MIRU 三部女性向互动剧试播设计包

日期：2026-11-20

本交付是三部新剧本的第一轮可执行内容设计：每部16章完整剧情骨架、前4章逐场试播文本、角色母档、隐性分支、每章两个小游戏、专属10秒预告与单张场景图制作单。所有成人角色为25岁以上。美术、音频和视频尚未实际生成。

## 文件清单

1. `01_Who_Is_Lying_To_Me_Story_CN.docx`：今晚谁在骗我。
2. `02_Too_Late_To_Want_Me_Back_Story_CN.docx`：离婚后他求我。
3. `03_I_Rejected_The_Alpha_Story_CN.docx`：狼王被我拒绝。
4. `04_Three_10s_Trailers_and_Character_References_CN.docx`：三支英文口语10秒预告及人物视觉母档，独立于剧情。
5. `05_Scene_Art_Briefs_First_Four_Chapters_CN.docx`：前4章共36张场景图的一对一制作说明。
6. 同名 `.md` 为可追溯、便于技术团队解析的源文稿。

## 交付范围判断

**已完成**：三部各16章的主题和因果结构；三部各前4章、每章3场、每章2项小游戏的试播设计；总计36场、24项小游戏的规则与胜负跳过说明；三份10秒预告；36张单幅CG的逐图需求。

**尚未完成**：三部第5—16章的逐场演出与自由回应完整稿；共144张完整CG中剩余的108张美术需求深化；实际角色参考图、36张试播CG的图像生成、视频MP4、英文全剧逐句本地化；完整24小时有效游玩内容容量的实际扩写和验证。不可把现有前四章样稿误当长篇全部成品。

## 制作规则

遵照《MIRU互动剧本写作规范 2026-11-17》：只有“扮演我自己”，玩家直接输入或AI轻提示，自由回复由后台匹配 `⟦OPT⟧` 隐藏分支；剧情界面不展示选项按钮；每章 `⟦GOAL⟧` 和 `⟦DONE⟧`；小游戏由故事内发生的活动引导而非独立大按钮；不让未做的模板被误认为已上线。

图像严格一张一张生成，不生成九宫格。美术先定妆，再按 `BG` 编号逐张 CG，统一采用 9:16 竖屏；音视频先根据 10 秒预告锁定单场景连续性。

三个主题的A/B测试建议分别看：10秒视频点击率、第一章进入率、首个自由发言完成率、玩家主动追问次数、前4章完成率、次日回访、关系延续与付费事件；该清单仅是测试建议，没有任何虚构基准或已获得数据。
