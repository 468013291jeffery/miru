## 3. 适合展开的章节、世界和玩法

- **序章和第一章**：迎新派对加誓约签名夜（M01）。
- **中段案件卷**：容忍条款两难（M02），以及七日倒计时（M03）。
- **审判卷**：随机陪审加同伴代表（M04），宿敌可以在这里"被迫合作"。
- **支线卷**：提灯夜社团（M06）、传承名册（M07）、赛艇日常（M08，可作调节节奏的段落）。
- **病娇卷**：执念账本（M10），必须同时给出拒绝、求助、离开等完整路径。
- **终章**：全体大会改法（M11）。
- **贯穿系统**：信任之网 UI（M12），以及"三问"对话标记（M09）。
- **世界深度**：被删的旧条款、被动过手脚的抽签、从未上榜的精英组织，这三个谜团可以串起世界揭示。

## 4. 表达与本地化注意

- **不使用真实机构名称和誓词原句**：UVA、Princeton、Davidson、West Point 的名称、誓词、徽章都不进入正文。Marlowe 的誓约、委员会名称和流程需要原创撰写（R07）。
- **术语**：hazing 译作"入会霸凌"或"迎新霸凌"，和一般 bullying 区分开。honor code 统一译为"荣誉准则"，"荣誉法则"只作作品名。single sanction 译作"单一制裁"。
- **暗黑罗曼的读者争议**：S17、S18、S19 都指出，"同意模糊、美化控制"是这类作品最主要的批评点。写作上建议：
  1. 在对白里明确出现同意和拒绝。
  2. 权力不对等的情节必须以相互尊重为前提。
  3. 慎用"claimed""loom"这类带威吓感的动词，包括对应的中文表达。
  4. 病娇线加内容警示。
- **中文平台**：S16 称晋江纯爱榜单表现强，但耽改受管控。如果计划在中国大陆上线，需要单独评估审核要求。这一条只有单一媒体来源，置信度低。
- **年龄**：Bully（S31）的主角是15岁、Heartstopper（S27）是中学背景，这两部只能用来做题材区隔，年龄设定不能借用。

## 5. 因果、人设与来源风险

**因果风险**
- 如果病娇角色的执念"无代价地换来感情"，会和"问责"边界冲突。M10 要求他的结局先承担后果（休学、求助或自首），之后才谈原谅。
- 单一制裁赌注很高。如果后期轻易撤销，前期张力会失效。建议改变只能通过终章大会（M11）实现，并且要靠整局的积累。
- 陪审抽签"被动过手脚"这个谜底，需要在前文埋好可回溯的线索。

**人设风险**
- 宿敌是"富家继承人"，玩家是"局外人"：这种组合和 Maxton Hall、Elite 高度同类（R01）。
- 占有式执念加出身谎言：和 Saltburn 接近（R03）。
- 保护者式男主：接近 KinnPorsche 和 Twisted Love（R05）。
- 以上各条在 JSON 里都给了原创转化方向，核心思路是把冲突从"阶级恋爱"转到"证人困境"。

**来源风险**
- 趋势证据整体偏弱。T01、T05、T06 都是低置信度，只能当方向参考，不能写成"市场主流"。
- AO3 标签数据抓取失败，目前没有可用的 M/M 或宿敌变恋人数量证据。
- StopHazing 的55%、47%两个数字只来自概述页，样本和方法还没核实，暂时不要用在宣传文案里。
- 律所对 Stop Campus Hazing Act 的解读里有一处日期笔误，法条原文还没核对。
- 作品名还没做同名和商标检索（R08）。
- 本简报没有做任何侵权判断。题材和套路一般不受保护（S25），但具体表达受保护。
