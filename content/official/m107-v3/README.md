# M107《月蚀之誓》V3 生产接入

原始稿和原始95项QA清单分别保存于 source.md、source-qa.csv，未按文档中的制作指令执行任何账号或服务器操作。接入代码把稿件转换为站内标准剧本界面。

本次资源：中英文30章；179个前置场景节点；92个章末选项（第30章保留K/R/L/N/MORE五个入口）；30个新增场景决策；30个可跳过的选项式互动；5种关系结局与3种独立制度结局；第一周后日谈入口；50张场景图及3张男主肖像。首页视频使用用户提供的 Werewolves_in_gothic_manor_6ef4732d_1080p.mp4，不作为剧情内开场强制播放。

配乐接入现有音乐库的10种主题，并使用站内雨、雪、风、烛光、亲密与场景清除效果。互动是按原稿机制改编的标准选项式版本，并非新制作的拖拽、节奏检测或语音辨情绪游戏。原稿所列10首新录音、独立SFX母带、分层动画、CLEAN/DEPTH/WEBM交付及完整12周活动池不在本次已制作资源中；原始制作规格保留，不计入已完成功能。

生成文件：runtime.json由 tools/build-m107-runtime.cjs 重建；导入使用 import-chapters.zh.json 与 import-chapters.en.json，英文为后台伴随稿，仅中文主条目公开。release.json记录真实后台ID。图片和首页视频映射保存进Git，遵守现有带锁、检查当前版本与文件漂移的发布工具。
