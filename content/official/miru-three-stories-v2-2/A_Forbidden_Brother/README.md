# 婚礼前夜，未婚夫的哥哥要我逃婚｜非视频提交包

以用户提供的 V2.2 制作包为文字母稿。`剧本.md` 是简体中文正文；`作品资料.md` 是首页、作品资料和最新人物母档。六语言版本保存在 `locales/`，图片与音频共用。

图片：`assets/images/` 提供封面1080×1920、人物与场景941×1672的JPG母图及同ID WebP副本。生成工具输出经裁切、重采样规范化；原始尺寸与输出尺寸记录在素材清单，封面有放大导出。`图片索引.html` 可离线浏览，点击进入JPG。提示词及索引在 `production/`。

音频：本作品3首BGM和3个音效，均为本次原创程序合成。WAV为44.1kHz／16bit／双声道，MP3为192kbps。BGM为完整乐句，循环时交叉淡化1秒，场景调用建议见 `production/audio_cues.json`；音效只在实际动作发生时触发。音频技术检查和制作方法有记录，未进行真人录音或母带工程师听审。

`production/asset_manifest.json` 为实际提交文件清单。图片是AI生成；不会因文件齐备而代表已经通过播放器或母语编辑验收。日韩西语原包缺少完整作品圣经翻译，保留现有本地化正文、首页与纲要；未擅自改写六语正文。小游戏保留候选设计，未冒称已接入。原包中的旧图文、旧版本和音频样稿不混入提交目录；原始ZIP与本地source仍保留。

未包含视频成品。视频制作文字稿保留在六语言目录，供后续制作参考。
