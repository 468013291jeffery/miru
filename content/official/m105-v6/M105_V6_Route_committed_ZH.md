# CHAPTER 1｜没有观众的周五
⟦GOAL|让角色在选择与后果中成长⟧
# SCENE｜烤焦的生日蛋糕
Mara 提前关门，把一个纸盒交给 Dante。盒子里的蛋糕像刚经历过一场厨房火灾。
Mara：“我让他买一个，他偏要自己做。”
Dante：“我有必要声明，烤箱在说谎。”
你们已经正式交往，却没有把这件事变成新闻或更换姓氏的仪式。墙上挂着居民奖学金委员会的合照，不是 Dante 的个人肖像。
他想牵你的手，突然想起你吃东西时有时不喜欢被打扰；你发现他迟疑，他笑了。
Dante：“我正在学习怎么做男朋友，不把恋爱当成公司职位。麻烦是，没有董事会会议纪要可参考。”
这原本是个能忘记码头案件的柔软夜晚——直到 Vince 来电：某个安保承包商仍在记录你的到达时间，尽管旧政策早已废止。

⟦FREE|你可以直接说话或行动，角色按前情回应。|提问|提出边界|提出新办法⟧
# SCENE｜记录本上的一行字
Dante 没有直接挂断，也没替你做主。他先问过你，才打开免提。
Vince：“外包公司沿用了旧签到系统。只记录时间，没有定位，但这东西本身就不该存在。”
Elena 也加入通话，说明你可以亲自查看记录，或授权独立审计员审核。
Dante：“我很生气，主要是因为我答应过不会再发生。我不是在要求你安慰我。”
你决定如何处理。没有人提议，因为你们恋爱了，就该放弃自己的法律权利。
报告提交后，他讲起母亲第一次拒绝父亲安保命令的故事。她保留自己的钥匙，从没为此道过歉。

# SCENE｜没吃完的蛋糕
夜里十一点，问题有了书面整改时间表和独立审查负责人。Dante 没说一切都解决了。你切下蛋糕还算完整的一角。
Dante：“可能还是很难吃。”
Mara：“你照着她当年的食谱做了。这样就够了。”
你从抽屉里找出一根小蜡烛。他隔着烛光望向你。
Dante：“我想跟你过普通的周五。普通到允许失望，也温柔到愿意再试一次。”
你不必说永远。今晚本身已经值得留下。

就在投票前，一位开发商提出，把拨款通过与莫雷蒂有关的公司管理。

# SCENE｜真正重要的一票
June 把开发商方案和居民自主管理方案并排展示。资金数字接近，差别在于五年后谁拥有土地。
June：“现在交出产权，我们的孩子以后可能还要付租金才能进入自己的花园。”
Dante：“那不是捐赠，是穿着漂亮鞋子的收购。”
你可以帮居民解释条款、联系独立律师，或留在观众席让他们自己主持。无论如何，Dante 不会拿恋爱关系为投票背书。
会议结束，他问你愿不愿意一起去海边小镇过周末。不搬家、不签租约，只是去一个没人认识你们姓氏的地方过两天。

# SCENE｜带着自己的钥匙回家
周末充满小发现：他喜欢开窗睡觉，你有固定的早餐习惯，社交多了之后你们都需要独处。
Dante：“我以前以为完美的房子能解决一切。现在我喜欢你能说‘我要回家了’，而且那个家真的是你自己的。”
你们各带一只行李箱回城。经过独立产权审查，花园表决最终支持居民方案。
在你家门前，Dante 握了一下你的手，随后等你自己开门。同居仍然可以是未来的选项，但不是故事强制发放的奖励。

# SCENE｜晚宴与明信片
Luca 的明信片一直放在桌上。Dante 没有追查邮戳。
Dante：“我想立刻坐飞机找他。但我不会。我可以等到他愿意发出邀请。”
晚宴上，June 代表居民委员会领奖。主持人刚想把 Dante 介绍为“拯救港口的男人”，他就礼貌纠正。
Dante：“这件事是委员会做成的。请念他们的名字。”
记者问你什么时候结婚。你可以回答、转移话题或拒绝。Dante 没有在你示意前抢答。
散场后，他脱下外套，递来一杯热茶，问你愿意一直选择的未来是什么样。

# SCENE｜承诺真正的样子
没有婚礼突然出现，没有音乐一起就必须求婚的桥段。
Dante：“我能给你的，是忠诚、包括让我难堪的真话，还有明天继续决定的自由。如果有一天婚姻对我们有意义，到时可以认真谈。”
你决定如何处理改正后的邀请函。上面印着的名字完全是你自己选择的。
他陪你走进夜色。这个夜晚不像终点，更像两个成年人普通生活的第一章。
