# SCENE｜用自己的钥匙开门
港口听证会几个月后，社区中心举办居民策展的摄影展。第一面墙写着创作者的名字；如果你选择署名，你的名字也在上面。
June：“总有人问是不是莫雷蒂出钱办的。不是。我们申请市政拨款，自己赢下来的。”
你独自到场，没有黑车等候，也没有暗藏在节目单里的约会邀请。
Dante 只是受居民邀请以普通访客身份出席，站在后排认真读说明牌。
Dante：“恭喜。听说最难的是把灯调好。”
如果你不想交谈，他接受礼貌点头，就让你继续享受自己的晚上。

# SCENE｜没人拥有的照片
记者提议拍一张你和 Dante 的“重逢照”，用于舞弊案件回顾。
记者：“大家喜欢重逢，这样结尾更干净。”
Elena 只在你需要时帮忙。这次展览不是任何人的复合舞台。
你可以拒绝合照、同意由居民主导的大合影，或者只接受没有恋爱问题的事实采访。
June 提醒记者，展厅里一半作品来自曾被迫搬迁的人。
Dante：“那就把他们的照片放头版。他们做了真正值得看的事。”
你第一次清晰感到，自己的人生已经拥有不依赖 Dante 的动力。

# SCENE｜以自己的名字离场
闭馆时，你用社区中心交给你的银色钥匙锁门。很小，但属于你。
Dante 只说了句晚安，没有附加承诺。你决定是否回应。
手机里是朋友祝贺展览的消息。你决定先回谁的电话。
结局不要求你重新考虑爱情来证明善良。独立不是惩罚，也不是等待被纠正的路线。

# SCENE｜证人不是传话筒
Nora 同意就她和 Luca 复制的账本作证。听证会在公开法院举行，她的住址和健康信息仍受保护。
Nora：“我不是想成为忠诚的象征。我只是想让人停止偷租户的钱。”
法官要求所有人不要把家庭私事写进案卷。Elena 如释重负地点头。
如果你提供支持，那是因为你尊重正当程序，不是因为你曾被亿万富翁爱过。
Dante 坐在公众席，没有接近 Luca 的代理人，也没让你帮忙传话。

# SCENE｜信封保持密封
听证会结束后，Elena 确认 Salvatore 的刑事程序不会因 Luca 是否愿意见家人而改变。

回家路上你经过面包店，想买一块柠檬挞，只是因为自己喜欢它，不是因为它让你想起 Dante。
拥有一段回忆，却不必因此回到一段关系，是另一种平静。

# SCENE｜谁有最后一句话
专栏作者想让你评价一个传言：你的独立是莫雷蒂公司安排的营销计划。
你有材料可以反驳，但不欠陌生人私人生活说明。如果你愿意，Elena 可以提供诽谤问题的建议。
Dante 听说后，明确让 Elena 不要替你发言，只提供基金会相关的公开财务文件。
Dante：“她的人生属于她。这句话不需要我的律师加工。”
你可以做有限更正、忽略报道，或把焦点带回公开社区会议。

# SCENE｜你自己决定的明天
夕阳下，你坐在工作室台阶上，听街区渐渐安静。一名学生走来问下一次展览什么时候开。
