# MIRU M110 · 12章中英双语同步升级包

## 文件清单
- `剧本_ZH.md`：中文旁白 + 美式英文角色台词（保留原双语玩家体验）
- `剧本_EN.md`：全美式英语旁白及角色对白；相同章/场/BG/分支/flag/MG
- `作品资料_ZH.md` / `作品资料_EN.md`：首页介绍、角色卡、前情和剧情、结局
- `小游戏_6个_完整双语规格.json`：6款游戏的具体玩法、题目、成功失败结果、双语文案、事件指标
- `素材提示词_48场.json` / `素材清单_48场.csv`：逐场图片提示词与人物视觉锁
- `音效配乐与配音清单_48场.json`：逐场环境声、配乐情绪、配音语言
- `关系状态与结局接入.json`：关系状态建议、5条角色线、关键分支兑现、结局数据契约
- `小游戏试玩_DEMO.html`：离线可玩的6游戏交互原型，中英文切换；不是MIRU应用内集成
- `双语同步验证.json`：静态结构一致性核对

## 同步规则
场景、`BG`、`IF/ELSE`、`OPT`、`SET`、`MG` 在两个文本中顺序和标识一致。通过语言选择决定叙述显示文案，状态/存档不依赖语言。角色原英文对白在两版保持一致。
