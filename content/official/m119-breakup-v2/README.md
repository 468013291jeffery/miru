# M119《全纽约最贵的分手事务所》发布包

本工程保留原始 ZIP 内的25份工程资料，并将64场剧情接入 MIRU 现有 native_v2 播放、自由输入、存档和语言切换流程。公开作品只使用一个“扮演我自己”入口。中文与英文正文、角色称呼、小游戏、结局和预告语音分别呈现。

## 内容与素材

- 16章、64场；256条主剧情隐藏意图，另有接听／拒接电话的两条意图。
- 32项可跳过的资料比对、顺序、权限分配、多项核验与预算小游戏。输掉记录核验成本，跳过走保守流程，均可继续。
- 8宗有独立授权、工作步骤、交付或转介结果的委托。法务工时与百万美元托管意向分别记账。
- 76张真人影视风格图片：70张基础素材与6张条件变体。使用内置生图工具；依据 source/assets 中 V2 提示词及用户视频固定形象。三张连续性问题已重做。成品在 art/official/m119-breakup-v2/images。
- 中英文各192段角色录音；16段原创程序化配乐、64段合成环境音。录音使用 Microsoft Edge neural speech，未克隆视频演员声音。
- 用户10秒原视频原样保留。中文版另配中文声音，复制原视频画面流，未重新编码画面。

原始资料是工程初稿，含重复制作说明与未实测的容量目标；这些说明没有进入玩家正文。本发布包不声称已实现或实测24小时游玩，也不声称无限生成新作者剧情。

## 状态与边界

主线沿用共享 Claude/自由输入流程。M119 模块只处理本作品的状态、素材、小游戏、委托与结算。角色只按在场或获准的远程通话发言。客户资料分开保管；拒绝合作、接听或恋爱不阻断案件。四类事件结果与关系意愿、责任修复、事务所安排分开呈现，听证不被写成刑事终审或已经生效的离婚。

实际作品、中文稿与英文伴随草稿 ID 见 binding.json。英文稿保留后台草稿状态，由中文作品的 en_sid 引用，不另发布成重复作品卡。

## 已执行检查

结构和样式检查：中英文均无硬错误；英文标题长度受到中文字符上限规则的提示，保留正常英文标题。

领域检查：12条完整意图／小游戏结果路线、失败／跳过继续、重复操作不重复扣费、旧状态拒绝、隐私记忆、双向同意、八宗委托和四类事件结果。

浏览器检查：390×844 Chromium 视口，实际共享队列走通64场并进入结局；32项小游戏在两种语言下分别成功、失败、跳过，共192次表单检查；存档 JSON 恢复和英文结局文字检查通过。为稳定检查导航，此检查替换了 AI 回复，不能视为线上模型语义识别测试；没有冒充真实手机硬件验收。

542个媒体文件均核对哈希并实际解码；原视频哈希与中文版本画面流一致性通过。结果分别见 browser-validation.json、media-validation.json 和 release-assets.json。

## 重建

Node 与 Python、ffmpeg 为运行依赖。素材已随包提供，正常构建无需重新调用生图或语音服务。

```text
node tools/compile-m119.cjs
node tools/finalize-m119-scripts.cjs
node tools/assemble-m119.cjs
python source/build.py
node --check source/all.js
node tools/m119-selftest.cjs
node tools/m119-release-check.cjs
```

发布使用已安装的 miru-deploy 入口，以完整提交 SHA 和精确线上目录进行核对；不直接覆盖线上目录，也不跳过指纹检查。validation.json 中的 published 字段与实际线上核验分别记录，不能将本地准备完成等同于已经上线。
