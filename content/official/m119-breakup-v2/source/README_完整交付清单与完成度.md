## 已锁定的用户要求
- 美国成年女性向，玩家28岁女性创业者；自我代入且不固定外貌。
- **真人影视风格，live action photorealistic，绝不使用漫画。**
- 人物必须在背景中做事情：递文件、开门、靠近又保持距离、协商、照顾客户，不是站立宣传照。
- 每章2个小游戏，第2和第3场内嵌，允许跳过、失败不封死主线。
- 英文台词自然口语，中文作者稿供研发理解；角色有独立意志，客户不因主线浪漫被工具化。
- 恋爱、经营、证据、人物弧光分四轴结算。拒绝前未婚夫不扣案件结果。
