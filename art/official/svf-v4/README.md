## 交付文件

- manifest.csv：统一槽位、相对路径、尺寸、格式、透明通道、来源方法及SHA-256。
- generation_prompts.json：按assets_v2和backgrounds_v1保留来源生成记录。
- validation.json：数量、槽位、尺寸、透明度、文件哈希和压缩包校验记录。
- documentation：两份原始成果说明，保留制作与替代镜头细节。

“完整”指本次图片素材范围：封面、角色状态图、章节高光、道具和普通场景底图；不包含另列的宣传海报、图标、分享图、预告缩略图、视频、音频或特效工程。
