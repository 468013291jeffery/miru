# SEVENFOLD《我在男团当团宠》场景底图库 v1

覆盖逐字剧本全部110个BG槽位。文件名为bg_c01s01.jpg至各章实际末场，保留原始章场编号，不擅自增加场号。

## 内容与制作口径

- 110个独立JPG文件，均为941×1672，导出质量85。
- 82个独立渲染版本：基础场景/机位与改光、陈设变化均分开制作。
- 28个复用槽位分别保存独立文件；manifest.csv明确写出复用来源，未将其计为新绘画面。
- 全部为适合叠加角色立绘与对白的环境底图。剧本BG描述中的人物行动由角色/高光层承担，未将主角固定烘焙在底图内。舞台观众仅作为远景光点氛围处理。
- 同一空间的改光版本使用基础图作参考，固定门窗、主家具与材质；临时陈设按剧情变化。
- 前一包的封面、角色、高光和道具不在本包重复收录。

## 原清单汇总差异

原汇总写27个空间、27张新图、38个改光、45次复用，但逐场正文还明确包含Jonah卧室、地下混凝土楼梯、车库木楼梯、车顶外景、电视台休息室、伦敦办公室等不同环境，且晚会、直播、病房照顾、搬离的陈设不能一概复用。

本包以110场正文描述及时间为准，将实际需要的环境/机位和状态分为82个成图版本，另28个同环境兼容槽位复用。具体分组公开列在manifest.csv中。

特别核对：bg_c07s04为Jonah卧室；bg_c18s06为伦敦泰晤士河景办公室；bg_c02s04、bg_c10s05为地下混凝土楼梯；bg_c03s06为车库木楼梯；bg_c04s05为车顶外景；体育馆演唱会使用体育馆环境，不沿用电视台沙发舞台。

## 文件

- backgrounds/：110张按槽位命名的正式尺寸图片。
- manifest.csv：槽位、文件路径、成图分组、复用来源、尺寸、导出质量、SHA-256及原文描述。
- generation_prompts.json：82个成图版本的最终提示词及基础图关联。使用内置图像生成制作。
- validation.json：文件数、独立成图数、尺寸格式与覆盖检查结果。

解压后保留backgrounds目录；播放器用槽位名读取对应JPG。源剧本文字中的Markdown转义不属于图片文件名，实际文件名没有反斜杠。
