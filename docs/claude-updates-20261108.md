# 发现页、我的页与故事智能体整合

发现页使用服务器排行榜、任务领取以及按口味排序的遇见卡片，保留 Claude Code 的 `9b83366` 改动。我的页按账号、钱包、故事、身份、收藏、偏好、声音排序，开发工具仅在开发模式显示，音色搜索同时匹配原名和译名。

故事引擎增加台阶路线、事件、秘密、小游戏邀请、音乐和可选感官旁白，支持每 20 轮后台压缩记忆，以及点名对话最多连续两轮跳过导演。

投票与任务的写入通过 `api/_boardwrite.js` 安装的 Postgres 函数在同一事务完成。按用户加事务锁，统一检查额度、请求幂等、钱包余额与账本；错误时回滚领取记录和扣钻。同一个请求键不能更换角色或票数。旧钱包接口不变。

小游戏邀请记录所在章与场景。完成时同时核对当前线程、章节、场景、卡片是否仍在、故事是否结束及回复是否忙碌；重复或过期回调丢弃。

## 验证

- `node tools/board-write-selftest.cjs`：隔离 Postgres 测并发额度、重试、扣钻、任务领取及异常回滚。依赖 `@electric-sql/pglite@0.2.17`，可通过 `MIRU_PGLITE_MODULE` 指向已有安装。
- `node tools/arc-runtime-selftest.cjs`：小游戏胜负、跳过、重复、换章、换场、换线程和故事结束后的回调。
- `node tools/manuscript-selftest.mjs`、`node tools/release-contract.mjs`、`node tools/check-all.mjs`：解析、现有作品契约与全量检查；基线已有失败单独记录，不通过改基线隐藏。
- 浏览器检查验证发现页、我的页、任务和投票流程，使用隔离账号、数据库和受控模型回答。

部署沿用 `ops/DEPLOYMENT.md` 的单一入口，保留生产环境配置和服务器适配器。

生产应用账号禁止建表：迁移先用已有的数据库 owner 环境安装 `votes`、`task_claims` 与 `miru_board_write`，再给运行账号这些表的读写权限、投票序列使用权限和函数执行权限。运行时仅检查迁移是否已安装；`MIRU_SKIP_SCHEMA=1` 时缺迁移返回 503，不尝试建表或替换函数。迁移账号凭据不进入仓库。
