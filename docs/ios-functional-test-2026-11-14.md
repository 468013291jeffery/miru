## 生产核验

只读核验当前 release 为 `/opt/miru/releases/05db359`。核心 `_lib` / `_apple` / `auth` / `_wallet` / `_iap` / `_voice` / `longcat` 与本地候选哈希匹配；Apple 私钥、Key ID、令牌加密密钥存在，PAY_TEST 未启用。未打印凭据或用户内容。

| 项目 | 当前证据 | 发布判断/最小下一步 |
|---|---|---|
| 社区服务端 | `api/works.js` 仍与候选不同；无已测试的原生筛选及作者屏蔽处理标记。 | 提审前优先补齐并复测。客户端已有拉黑作者及 blocked 列表调用，不能把本地规则测试通过当作线上可用。对应 Apple 1.2 的过滤、举报、屏蔽要求；具体实现方案不是 Apple 强制规定。 |
| 译文隐私 | `api/i18n.js` / `api/translate.js` 仍是旧版，缺少公开词条发布筛选；实际公开接口响应仍是 public 缓存策略。 | 数据隐私上线前事项：部署已验证的隔离规则并核对历史 CDN 缓存。未读取或输出真实用户译文来扩大验证。 |
| 语音归属与删除 | `api/tts.js` 仍是旧版，未使用已测试的 voice registry/helper；生产未配置 MIRU_VOICE_DIR / MIRU_VOICE_STORE_ID。 | 首发保留录音/音色功能时，需核对归属、删除及实际保存位置。目录配置本身是工程手段；隐私/账号删除行为才是必要结果。 |
| 隐私/条款页面 | 两个公开 URL 均 HTTP 200，但线上文件与已验证候选不同。 | 不能仅以链接可访问视为披露准确；部署前核对实际 AI 接收方、保留期限及现有能力，避免声明超出实际部署。 |

尝试通过公开 guest 接口创建专用合成账号，实际返回 403，未创建账号，未写入云进度、钱包或任何正式用户数据。因此本轮线上合成账号云同步/注销探针未执行；此结果不作为产品缺陷，也没有为测试开放 guest 注册。
