# 消息渲染：两条路径，一个该并的地方

> 2026-10-27 凌晨，Ann 对着截图问「这个不是应该他里面有个模版，直接套就行了吗？」
> 答案：模板有，但是**两个**。这份文档记下两者差在哪、为什么现在看起来不一样、以及合并的判据。

## 一、现状：两条渲染路径

| 渲染器 | 文件 | 谁走这条路 | 结构 |
|---|---|---|---|
| `msgHTML(m, i, th)` | `source/src/app3_chat.js` | **模型现写的回复**、玩家自己的话、旁白、卡片、图片、导演指令 | `<div class="m-row (me)">` + 头像 + `.m-who` + `.bub`（+ 底下那排 `重新生成/编辑/他在想什么`） |
| `boxHTML(m, i, th)` | `source/src/app16_story2.js` | **剧本/叙事合并块**（`k === "box"`） | 一个 `.m-box`，里面每个 part 一行 `<p class="bac|bth">` |

合并的逻辑在 `pkAppend`：非旁白直接 `appendMsg`（走 `msgHTML`），旁白与角色短句会被并进同一个 `box`（走 `boxHTML`）。

**所以「为什么这条有框、那条没有」的答案是：它们由两个不同的人写、在两个不同的文件里、各自维护一套样式。**

## 二、视觉差在哪（2026-10-27 已用 CSS 对齐，但骨头还是两套）

| | `msgHTML` | `boxHTML` |
|---|---|---|
| 名字 | `.m-who`，单人剧里曾被藏掉（已修） | `<b>` 内联在段首 |
| 色条 | 我加的 `border-left` on `.bub`（`--wc`） | 无（只有名字带色） |
| 头像 | 有（左下角 30px） | 无 |
| 交互按钮 | 有（重新生成/编辑/他在想什么） | 无 |
| 左右分边 | `.m-row.me` + `margin:auto` | 2026-10-27 起按 part 的 who 分 |

## 三、该并的方向

**让 `msgHTML` 的角色台词复用 `boxHTML` 的结构**，而不是继续用 CSS 去模仿。要点：

1. 抽出**一个**「角色一句话」的渲染函数（暂名 `lineHTML(part, th, opts)`），`boxHTML` 的每个 part 和 `msgHTML` 的单条 `say` 都调它。
2. `msgHTML` 独有的东西（头像、`data-*` 交互按钮、解锁态）作为 `opts` 传进去，而不是各写一套。
3. 玩家自己那句同样走 `lineHTML`，靠 `who === "me"` 分边 —— 现在两处都在各自处理这个判断。

## 四、验收判据（合并之后必须同时成立）

- [ ] 同一句话，无论来自模型还是剧本，**DOM 结构完全一致**（同一组 class）
- [ ] `data-mi` / `data-redo` / `data-edit` / `data-mind` / 解锁按钮**一个不少**（合并最容易丢的就是这排）
- [ ] 单人剧也显示名字
- [ ] 玩家那句在右、角色在左，两种来源都成立
- [ ] `tools/check-all.mjs` 全绿，且**页面在真浏览器里 0 语法错误**
- [ ] 改一处样式，两个来源同时变（在浏览器里改一行 CSS 验一次）

## 五、为什么现在没做

这是结构性改动（要搬交互按钮和事件绑定），凌晨五点动手、中途她又会刷新，风险不对等。
`aa10a11` 先用 CSS 把视觉对齐，能玩；**并骨头留到有人看着的时候**。
## 六、2026-10-27 晚：合并已落地（本节覆盖第五节）

`lineHTML(part, th, opts)` 已经抽出来了，两个渲染器都在调它：

    boxHTML   = <div class="m-box"> + parts.map(p => lineHTML(p))        // 输出与合并前一致
    msgHTML   = 头像 + .m-who + <div class="m-box lb"> + lineHTML(..., {noName:true})

「框」本来就在 `.m-box` 上（padding / 圆角 / 半透明底 / 模糊），不在 `.bac` 上 ——
所以之前我在 `.bub` 上手画边框怎么画都不像；现在模型那条也装进了同一个 `.m-box`。

两处兜底：`lineHTML` 在 app16_story2.js，调用点在 app3_chat.js，两个调用点都写了
`typeof lineHTML==="function"` 的回退，加载顺序变化时退化成旧样式而不是白屏。
`{noName:true}` 是因为 msgHTML 上方已经渲染了 `.m-who`，不传会重复一次名字。

第五节列的六条判据里，第 1（结构一致）、第 3（单人剧显名字）、第 4（左右分边）、第 5（全绿 + 0 语法错误）已过；
第 2 条（那排「重新生成/编辑/他在想什么」按钮一个不少）**只做了静态核对，没有在真机上点过** —— 这是今天欠的一步。
