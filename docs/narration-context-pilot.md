# 剧情旁白 v2 全量接入与玩家输入类型

所有剧本运行时默认使用旁白 v2，覆盖 b98、agent97、旧 pk / playBeats。现有存档继续原引擎和原进度；不需要逐作品打开开关。今后上传的中文稿默认写入 narration.schema=2 与 context.schema=1；旧 JSON 和内置剧本也通过运行时默认接入。

《零点王冠》保留 20 组双语作者材料及原有解锁条件。其他作品从当前已经展示的章节导语、实际人物表演和已经公开的事件／秘密回执组织旁白；不会把未发生的 beat 或未来秘密送入旁白模型。没有额外作者线索时，旁白不擅自创造证据或安排结局。调查回合可以引用本轮已经说出口的记录相关陈述作为来源，明确“说过”与“已核实”的区别；格式异常或复核不通过时仍保留可核对的公开原话，不把它升级成世界真相。

玩家输入统一使用 say / act / think：界面显示为「台词」、*动作*、（心声）。AI 建议使用 {mode,text} 明确类型，发送时只保存正文和类型；标识在渲染时补上。括号不再转换为公开动作。模式菜单保留草稿，中文输入法组词时不改写输入。旧的含糊建议缓存重新生成；剧本预设的“让／要求某人……”按示意动作处理，表示尝试而非 NPC 已经照做。

心声不进入角色的公开对话与旁白；心声回合的导演意图在传给角色前替换成“玩家沉默”，防止把私密正文夹带给角色。

## 叙事内容与篇幅

八章共 20 组双语材料，来源是已有章节导语和场景 beat，覆盖场景环境、调查方向、旧印交接、记忆异常、龙谷责任、预言条件、谈判条款、王冠代价与错误指控。没有新增示例中假设的日期矛盾或任何改变原稿走向的证据。

场景开场 100–450 字；调查、线索、选择后果 90–450 字；重大揭示 160–450 字；快节奏互动 40–140 字。按内容选择预算，不再统一 90 字或三轮一次。重要问题可连续获得旁白，普通互动至少留出一个角色回合。明确想安静、玩家心声、失败表演不强加说明。

导演输出 narration_plan，选择允许的 material 和 before/between/after 位置。开场先用作者段落建立环境与问题；前置或人物之间的作者段落立即显示，随后角色能收到实际公开的事实。后置旁白读取本轮真实表演，自由组织一到三段，并经过有截止时间的语义复核。它不能用引用编号替代对动作主体、承诺性质或新事实的判断。

## 事实、线索与秘密

材料按章节、场景、可选前置事实、指定人物好感和选择回执放行，玩家问题的具体匹配优先于泛泛关键词。王冠代价和错误指控只在第七章起开放；第八章仍能追问，不受恋爱好感或游戏输赢限制。私人线索可只给玩家，不能自动变成其他人物的知识。

模型只收到本轮可释放材料、已知记录和实际表演，不接收未放行的完整秘密。模型有自然描写的空间；语义复核失败、超时或输出不合格时，使用当前材料完整的作者段落，不输出“某某给出了回应”。没有可用材料时不靠空话凑段落。

旁白实际写入聊天后才记录发现、已展示标记和节奏状态。迟到输出校验线程、状态对象、场景、轮次、消息边界；前置和人物间的段落也绑定原始状态对象。重新生成、版本切换、保存恢复都携带这些记录。

## 上下文

新增旁白把 facts 与 prose 分开。角色输入保留有见证范围的简洁事实与来源，不重复携带整段文学描写；气氛文字不成为世界事实。只给玩家的观察不会进入角色输入。旧 pk / agent97 通过原世界的作品 ID 接入，不改引擎，不重建或清除进度；未知旧场景只使用实际表演，不借用其他章节的秘密。

已有作品保留原有角色记忆与压缩配置，新增旁白不把整段文学描写重复塞进角色输入。原有边界、承诺性质和小游戏真实回执保留。作品资料请求包含构建版本，刷新到新版时同步取得新版叙事配置。

## 实现与验证

- source/src/app145_narration.js：桥段调度、自由旁白、语义复核、作者降级、事实账本。
- content/official/zero-crown-v3/narration.json：双语作者材料及来源。
- tools/build-narration145.cjs：可重复生成并检查试点圣经，原 prepare-zero-crown 也调用它。
- app98_story、app135_context、app3_chat、app73_features：前中后接线、见闻记忆和版本恢复。
- tools/narrative145-selftest.cjs：解锁、私密范围、词题匹配、迟到结果、失败降级和旧局。
- tools/narrative145-browser.cjs：实际构建页面中的插入顺序、角色收到新线索、长段落、揭示和存档。
- tools/narrative145-live.cjs：隔离测试读者，保留真实导演、角色、旁白和语义检查。MIRU_LIVE_ORIGIN 可指定公开网站；curl 使用 MIRU_TEST_PROXY 接通同一个线上模型接口，避免测试工具 TLS 故障，不预设模型回答。MIRU_MODEL_TRANSPORT=ssh 可从服务器本机调用同一生产后端，报告标明实际通道。

发布继续走安装在服务器上的 miru-deploy 守卫，校验精确当前版本与指纹。新增 tools/input146-selftest.cjs、input146-browser.cjs 与 input146-live.cjs 覆盖类型、手机菜单、中文输入法、全部本地剧本策略、三种引擎和未来上传。
