# iOS 账号与个人内容清理
首发范围仅包含正常登录、Apple 授权撤销、可重试注销及有归属记录的个人内容清理。本轮没有操作生产数据库或真实 Apple 授权。

## 上线配置
- 服务端私密配置 APPLE_KEY_ID、APPLE_PRIVATE_KEY（P-256 p8）、APPLE_TOKEN_ENCRYPTION_KEY（base64 的32字节随机密钥）。不要放入 App、仓库或聊天。
- 原生 Bundle 为 com.miru.plus.app，Team 为 H79A5X8935。网页 APPLE_CLIENT_ID 保持现有 Services ID；网页 code 流程的 APPLE_REDIRECT_URI 须匹配登记回调。
- 正常素材删除需要可用的 BLOB_READ_WRITE_TOKEN。失败保留素材引用并允许重试。
- MIRU_VOICE_DIR 必须指向部署实际使用的持久录音目录；MIRU_VOICE_STORE_ID 标记存储身份。显式目录不可用会停止操作，不能借此认定实际生产挂载已验证。
- 在真实 iPhone/TestFlight 验证 Apple 登录、取消、注销失败重试、注销成功和重新授权。前端在暂时失败时必须保留登录令牌。
- 财务订单和流水保留；注销清除个人进度、记忆、作品、已登记素材与录音、余额及购买账号绑定。隐私说明须如实披露必要记录保留。

## 延期范围
历史无归属录音、失去数据库引用的对象盘点，以及上传与注销极端并发治理在首发后单独处理；不宣称历史数据已全部清理。未登记历史录音可播放，但不能由任意登录账号删除或认领。旧 Apple 网页账号无可撤销授权时需在 App 内重新认证后注销。
本次未发布的通用数据库写入守卫、上传预留和历史对账原型已移出运行代码；不需要为首发执行历史清理命令。
